# Lab4 Task1 延迟测量自动化 - 快速开始

## 快速使用

### 1. 生成所有测试文件（一键生成）

```bash
cd /path/to/Lab_Project/DIC/Lab4/Task1
python3 generate_sp.py --fa-type both
```

这将在 `FA16/delay/` 和 `FA28/delay/` 目录下生成 48 个 HSPICE 测试文件。

### 2. 运行 HSPICE 仿真

**注意**: 需要在有 HSPICE 的环境（如 PowerShell）中运行

```bash
# 在 PowerShell 中运行所有仿真
python3 run_sp.py --base-dir .

# 或者只运行 FA16 的仿真
python3 run_sp.py --base-dir . --fa-type FA16

# 或者只运行 FA28 的仿真
python3 run_sp.py --base-dir . --fa-type FA28
```

### 3. 解析结果并生成统计报告

仿真完成后，运行：

```bash
python3 parse_delay.py .
```

这将生成：
- `delay_summary.csv` - 所有测试的详细延迟数据
- `delay_summary.xlsx` - Excel 格式的数据（便于分析）
- `delay_summary_stats.txt` - 统计摘要

## 测试模式说明

脚本现在生成更精确的测试模式：
- **Sum 输出**：每个输入 4 种转换 = 12 种测试
- **Cout 输出**：每个输入 2 种特定转换 = 6 种测试
- **总计**：每种 FA 有 18 个测试

### Sum 输出测试（12个）：
1. **A → Sum**: 4种转换 (A从0→1，B和Cin所有组合)
2. **B → Sum**: 4种转换 (B从0→1，A和Cin所有组合)
3. **Cin → Sum**: 4种转换 (Cin从0→1，A和B所有组合)

### Cout 输出测试（6个，特定转换）：
序列顺序为 A B Cin：
4. **A → Cout**: `001→101`, `010→110`
5. **B → Cout**: `100→110`, `001→011`
6. **Cin → Cout**: `100→101`, `010→011`

### 文件夹命名规则：
每个测试在独立文件夹中，命名格式：`输入信号_初始状态_最终状态_输出信号`
- 例如：`CI_100_101_CO` 表示 Cin从100→101，测量Cout
- 例如：`A_000_100_S` 表示 A从000→100，测量Sum

## 输出文件说明

### HSPICE 仿真生成的文件：
- `.sp` - HSPICE 输入脚本
- `.lis` - 仿真输出日志
- `.mt0` - 测量结果文件（被 parse_delay.py 解析）
- `.tr0`, `.ic0`, `.st0` 等 - 中间文件（可删除）

## 常见问题

### Q: HSPICE 命令找不到？
A: 确保在安装了 HSPICE 的环境中运行，并且 `hspice` 命令在 PATH 中。

### Q: 仿真运行很慢？
A: 48 个测试需要一定时间，可以用 `--fa-type` 参数分批运行：
```bash
python3 run_sp.py --base-dir . --fa-type FA16  # 先运行 FA16 (24个)
python3 run_sp.py --base-dir . --fa-type FA28  # 再运行 FA28 (24个)
```

### Q: 如何只运行部分测试？
A: 可以手动进入特定的 delay 目录，然后在该目录运行：
```bash
cd FA16/delay
hspice FA16_delay_A_to_Sum_B0_Cin0.sp > FA16_delay_A_to_Sum_B0_Cin0.lis
```

### Q: 需要安装什么 Python 包？
A: 需要 pandas 和 openpyxl：
```bash
pip install pandas openpyxl
```
