## 9.（12分）
数字集成电路的设计流程中，逻辑综合将RTL代码综合为由工艺库中的标准单元所构成的门级网表。比如下图的方框中就给出了ISCAS85 Benchmark中的C17组合逻辑电路在某工艺下的综合后门级网表。在标准单元工艺库中，同逻辑功能的门可能有不同尺寸的单元可供选择，比如对于2输入与非门NAND2来说，工艺库中可能存在NAND2X1、NAND2X2、NAND2X4、NAND2X8等，分别代表尺寸为1、2、4、8等；对于反向器INV来说，还可能存在更大尺寸的INVX16。而不同尺寸的逻辑门，会具有不同的延迟、功耗、面积，一般来说大尺寸的逻辑门速度更快，但面积更大，对输入端也要求更大的门做驱动，否则会由负载原因导致延迟变劣。在研究中，门级网表有一种优化方法是调整标准单元的尺寸，比如把示例的C17中的U7换为NAND2X2，则电路整体逻辑功能不变，但会具有不同的性能。假设你已经有了一个函数eval()可以快速评价任何一个组合逻辑电路门级网表的性能（eval()函数返回值越高视作性能越优）。请设计一个基于遗传算法的优化算法，通过自动调整各个门的尺寸优化电路整体性能，要求给出问题的求解方案以及算法设计方案，包括遗传算法设计方案，且算法代代应与求解问题相关，不能只默写一下标准代码框架。

附C17电路门级网表代码：
```
module c17( N1, N2, N3, N6, N7, N22, N23); 
input N1, N2,N3,N6,N7;
output N22,N23;
wire n1, n2, n3, n4;
NAND2X1 U7(.A(N6),.B(N3),.Y(n1));//尺寸为1的2输入与非门
NOR2BX1 U8(.AN(n1),.B(n2),.Y(N23));//尺寸为1的NOR2B 
NOR2X1 U9(.A(N2),.B(N7),.Y(n2));//尺寸为1的2输入或非门
NAND2X1 U10(.A(n3),.B(n4),.Y(N22));//尺寸为1的2输入与非门 
NAND2X1 U11(.A(N1),.B(N3),.Y(n3));//尺寸为1的2输入与非门 
NAND2X1 U12(.A(N2),.B(n1),.Y(n4));//尺寸为1的2输入与非门
endmodule
```
