\section{Introduction}

本实验基于PTM 16HP FinFET工艺，对两种全加器电路（16T FA和28T FA）及其构成的8位加法器链路进行了仿真与性能分析。实验主要聚焦于延迟（delay）和功耗（power）两个关键性能指标的测量与比较。

\subsection{实验全局配置}

本实验采用HSPICE进行电路仿真，仿真环境配置如下：

\begin{enumerate}
    \item 工艺库：PTM 16HP FinFETs
    \item 仿真等级：RUNLVL = 6
    \item 栅极长度：$L_g = 20$nm
    \item 供电电压：$V_{\text{DD}} = 0.75$V
    \item 仿真温度：$T = 25^\circ\mathrm{C}$
\end{enumerate}

\subsection{全加器电路设计}

实验中使用了两种不同的全加器电路设计：

\subsubsection{16T全加器（FA16）}

16T全加器采用传输门（pass transistor）逻辑，共使用16个晶体管，具有较低的晶体管数量，但可能在某些输入模式下性能不及28T全加器。其逻辑表达式为：

\begin{align}
\text{Sum} &= A \oplus B \oplus C_{\text{in}} \\
C_{\text{out}} &= (A \oplus B) \cdot C_{\text{in}} + (A \odot B) \cdot A
\end{align}

其中$\oplus$表示XOR运算，$\odot$表示XNOR运算。

\subsubsection{28T全加器（FA28）}

28T全加器采用标准CMOS逻辑门设计，共使用28个晶体管（包括2个反相器），具有更对称的上拉网络（PUN）和下拉网络（PDN），理论上具有更好的噪声容限和更均衡的延迟特性。其逻辑表达式为：

\begin{align}
C_{\text{out}} &= AB + (A+B) \cdot C_{\text{in}} \\
\text{Sum} &= ABC_{\text{in}} + \overline{C_{\text{out}}}(A + B + C_{\text{in}})
\end{align}

\section{Task 1: 全加器性能分析}

\subsection{电路搭建}

Task 1中分别对16T全加器（FA16）和28T全加器（FA28）进行了性能测试。每个全加器的输入端（A、B）通过buffer与激励源连接，输出端（Sum、Cout）各连接一个尺寸为2的反相器作为负载。

\subsection{激励源和输入模式说明}

\subsubsection{延迟仿真输入模式}

为了全面测量全加器的延迟特性，实验对所有可能的输入转换进行了仿真。延迟测量包括：

\textbf{1. 输入到Sum的延迟}（每个输入信号4种模式，共12种）：
\begin{itemize}
    \item A $\rightarrow$ Sum：固定B和$C_{\text{in}}$的4种组合（00, 01, 10, 11），A从0到1跳变
    \item B $\rightarrow$ Sum：固定A和$C_{\text{in}}$的4种组合（00, 01, 10, 11），B从0到1跳变
    \item $C_{\text{in}}$ $\rightarrow$ Sum：固定A和B的4种组合（00, 01, 10, 11），$C_{\text{in}}$从0到1跳变
\end{itemize}

\textbf{2. 输入到$C_{\text{out}}$的延迟}（每个输入信号2种模式，共6种）：
\begin{itemize}
    \item A $\rightarrow$ $C_{\text{out}}$：$ABC_{\text{in}}: 001\rightarrow 101, 010\rightarrow 110$
    \item B $\rightarrow$ $C_{\text{out}}$：$ABC_{\text{in}}: 100\rightarrow 110, 001\rightarrow 011$
    \item $C_{\text{in}}$ $\rightarrow$ $C_{\text{out}}$：$ABC_{\text{in}}: 100\rightarrow 101, 010\rightarrow 011$
\end{itemize}

以上任意翻转信号的定义均为延迟500ps，上升时间和下降时间均为50ps，高电平维持时间为950ps，周期为2s的脉冲波，例如：
\begin{lstlisting}
VA Ain GND PULSE (0 'SUPPLY' 500p 50p 50p 950p 2n)
\end{lstlisting}
每种模式下测量$t_{\text{pLH}}$和$t_{\text{pHL}}$，并计算平均延迟$t_{\text{p}} = (t_{\text{pLH}} + t_{\text{pHL}})/2$。

\subsubsection{功耗仿真输入模式}

功耗仿真采用动态激励模式，三个输入端（A、B、$C_{\text{in}}$）施加周期性脉冲信号，频率依次减小$\frac{1}{2}$，使电路在运行过程中遍历所有$ABC_{\text{in}}$组态。即：
\begin{lstlisting}
VA Ain GND PULSE (0 'SUPPLY' 500p 50p 50p 1950p 4n)
VB Bin GND PULSE (0 'SUPPLY' 500p 50p 50p 950p 2n)
VCI CIin GND PULSE (0 'SUPPLY' 500p 50p 50p 450p 1n)
\end{lstlisting}

\subsection{面积计算}

电路面积以晶体管数量为度量标准。根据HSPICE子电路定义：

\textbf{FA16面积}：
$S_{16} = N\times \text{Fin\_number} \times \text{Width\_fin} \times L_{g} = 16\times 1\times 12\text{nm} \times 20\text{nm} = 3840 \text{nm}^2$

\textbf{FA28面积}：
$S_{28} = N\times \text{Fin\_number} \times \text{Width\_fin} \times L_{g} = 28\times 1\times 12\text{nm} \times 20\text{nm} = 6720 \text{nm}^2$

\textbf{结论}：
\begin{enumerate}
    \item FA16在$C_{\text{in}}$相关路径上表现优异，特别是$C_{\text{in}} \rightarrow C_{\text{out}}$路径（1.95ps），这是由于其传输门逻辑的直接传输特性

    \item FA16的整体平均延迟（9.76ps）优于FA28（13.48ps），但FA16在某些路径上存在较大延迟（如B $\rightarrow$ $C_{\text{out}}$：13.91ps）
\end{enumerate}

\subsection{功耗仿真结果与分析}

对FA16和FA28在相同动态激励下的功耗测量，激励模式和测量语句见：

\section{Task 2: 8位加法器链路性能分析}

\subsection{电路搭建}

Task 2构建了两种8位加法器链路：
\begin{itemize}
    \item \textbf{Adder1}：由8个FA28串联组成
    \item \textbf{Adder2}：由4个FA28和4个FA16交替排列组成（位置：FA28-FA16-FA28-FA16-FA28-FA16-FA28-FA16）
\end{itemize}

每个全加器单元都包含输入buffer（用于隔离输入端），以及输出负载（尺寸为2的反相器）。链路中，前一级的进位输出$C_{\text{out}}$连接到后一级的进位输入$C_{\text{in}}$。

\subsection{激励源和输入模式说明}

\subsubsection{延迟仿真输入模式}

延迟仿真测量从$C_0$（初始进位输入）到两个关键输出的传播延迟：
\begin{itemize}
    \item $C_0 \rightarrow C_{\text{out}}$（最终进位输出）：测量进位信号沿链路传播的延迟
    \item $C_0 \rightarrow S_7$（最高位和输出）：测量进位信号影响最高位和输出的延迟
\end{itemize}

输入条件：A[7:0] = 11111111（全1），B[7:0] = 00000000（全0），$C_0$施加脉冲激励（延迟500ps，上升下降时间均为50ps，高电平维持时间为950ps，周期2ns）。这种输入模式确保进位信号需要通过所有8级全加器传播。HSPICE激励定义：
\begin{lstlisting}

Vdd2 VDD2 GND DC 'SUPPLY'
VA0 A0 GND DC 'SUPPLY'
VA1 A1 GND DC 'SUPPLY'
VA2 A2 GND DC 'SUPPLY'
VA3 A3 GND DC 'SUPPLY'
VA4 A4 GND DC 'SUPPLY'
VA5 A5 GND DC 'SUPPLY'
VA6 A6 GND DC 'SUPPLY'
VA7 A7 GND DC 'SUPPLY'
VC0 C0 GND PULSE (0 'SUPPLY' 500p 50p 50p 950p 2n)
\end{lstlisting}

\section{Observations and conclusions}

本实验围绕单级全加器（FA16、FA28）及其8级串联链路（Adder1、Adder2）的延迟、功耗与面积进行了对比，主要观察结论如下：

\begin{enumerate}[label=\arabic*)]
    \item \textbf{Task1（单级全加器）性能取舍}：
    \begin{itemize}
        \item 延迟：FA16在与$C_{\text{in}}$相关的路径上延迟显著更小（例如$C_{\text{in}}\rightarrow C_{\text{out}}$仅1.95ps），整体平均延迟9.76ps也优于FA28（13.48ps）。
        \item 功耗：FA16功耗（0.2039$\mu$W）远低于FA28（1.009$\mu$W）。功耗与晶体管数量和翻转节点数正相关，FA16因管数少优势明显。
        \item 信号质量：FA16在$C_{\text{in}}$翻转时出现毛刺，这是因为传输门逻辑的不可再生性和驱动能力有限；FA28波形更平滑、鲁棒性更好。
    \end{itemize}

    \item \textbf{Task2（8位链路）级联效应}：
    \begin{itemize}
        \item 延迟：混合链路Adder2（FA28+FA16交替）在$C_0\rightarrow C_{\text{out}}$和$C_0\rightarrow S_7$路径上分别达到72.4ps与80.24ps，均优于全FA28的Adder1（102.50ps、112.30ps）。说明在关键级加入低延迟单元能有效压缩整体进位时间。
        \item 功耗：Adder2平均功耗3.173$\mu$W，较Adder1（4.994$\mu$W）下降约36.5\%，与晶体管数量减少及翻转节点下降一致。
        \item 面积：Adder2面积比Adder1减少约21\%（42420nm$^2$ vs. 53760nm$^2$），体现混合方案在面积与功耗上的协同优势。
    \end{itemize}

\textbf{设计启示}：

在需要极低延迟的关键进位通路，可适度使用传输门型FA16以压缩临界路径；但需搭配合适缓冲或CMOS级以抑制毛刺、恢复逻辑电平。若设计更看重鲁棒性、噪声容限与模式一致性，FA28更适合作为基线单元；在大规模级联时可交替或分段使用FA16，平衡速度、功耗与信号完整性。
\end{enumerate}

综合来看，混合架构（Adder2）在延迟、功耗与面积上取得了较均衡的优势，但仍需在信号完整性与毛刺抑制上做进一步优化，以确保在更高频率或更大规模级联下的可靠性。
