非常好的问题——你现在问的这个，其实正是 **组合数编号（combinatorial number system）** 的核心思想。
它在 TSP 的 DP（Held–Karp）中非常有用：
👉 可以在不显式枚举所有子集的情况下，**直接根据一个掩码 `a` 计算它在“包含 N 个 1 的所有掩码集合 SN”中的位置索引 b**。

---

## 🧩 问题重述

我们定义：

* `a`：一个宽度为 M 位的二进制数；
* `N`：其中恰好有 N 个 1；
* `S_N`：所有宽度为 M、恰有 N 个 1 的二进制码组成的集合；
* 这些二进制码 **按数值从小到大排列**；
* 我们要计算：`index(a)` = `b`，即 `a` 在该序列中的位置。

例如：

```
M = 5, N = 3
S_3 = { 00111(7), 01011(11), 01101(13), 01110(14),
         10011(19), 10101(21), 10110(22), 11001(25),
         11010(26), 11100(28) }

假设 a = 10110 (22)
=> index(a) = 6 （从0开始）
```

你希望能在不生成 S₃ 的情况下，直接从 (a, M, N) 得到 b。

---

## ✅ 思路核心：**组合数编号法**

每个这样的掩码可以看作是「从 M 位中选 N 位为 1」的一种组合。
因此，掩码集合 `S_N` 与组合集合：
[
{ C(M,N) = {i_1 < i_2 < \cdots < i_N} }
]
是一一对应的。

---

### 🧠 思想解释

把 `a` 的二进制位编号为 `[0, 1, ..., M-1]`（从低位到高位），
假设 `a` 中的 1 出现在位置：
[
pos = [p_1, p_2, ..., p_N] \quad (p_1 < p_2 < ... < p_N)
]
那么该组合在所有组合中的“字典序排名”公式为：

[
index(a) = \sum_{i=1}^{N} \binom{p_i}{i}
]

这里的下标含义要注意：
`p_i` 是第 i 个 1 的 **位置**（从 0 开始），
`i` 是第几个 1（从 1 开始）。

---

### 📘 示例验证

以你上面的例子为例：

```
M = 5, N = 3
a = 10110₂
位编号: [4,3,2,1,0]
             ↑ ↑  ↑
位置 pos = [1, 2, 4]  （1 在 bit1、bit2、bit4）
```

根据公式：
[
index = C(1,1) + C(2,2) + C(4,3)
= 1 + 1 + 4 = 6
]

✅ 完全符合之前手动枚举得到的 index = 6。

---

## ⚙️ 一般公式（从低位到高位）

设：

* `a` 的第 i 位（从低到高）为 bit[i]；
* `cnt` 表示已经发现的 1 的数量；
* 我们从低位到高位遍历每一位，如果该位是 1，则：
  [
  index += \binom{i}{cnt+1}
  ]

---

## 🧮 C++ 实现

```cpp
#include <cstdint>
#include <vector>
#include <iostream>

uint64_t combination_index(uint32_t a, uint8_t M, uint8_t N)
{
    auto C = [](uint32_t n, uint32_t k) -> uint64_t {
        if (k > n) return 0;
        if (k == 0 || k == n) return 1;
        uint64_t res = 1;
        for (uint32_t i = 1; i <= k; ++i)
            res = res * (n - i + 1) / i;
        return res;
    };

    uint64_t index = 0;
    uint8_t count = 0;
    for (uint8_t i = 0; i < M; ++i) {
        if (a & (1u << i)) {
            ++count;
            index += C(i, count);
        }
    }
    return index;
}

int main() {
    uint32_t a = 0b10110;
    uint8_t M = 5, N = 3;
    std::cout << "Index = " << combination_index(a, M, N) << std::endl;
    // 输出应为 6
    return 0;
}
```

---

## ✅ 时间复杂度与优点

* 仅需 (O(M)) 时间；
* 不需显式生成所有组合；
* 精确无误差；
* 可在 TSP DP 中实现 “子集索引压缩存储”；
* 对 29 位（M=29）完全没问题。

## 🔁 逆过程（可选）

如果你已知 `(M, N, index)`，也可以反向构造掩码 `a`：

算法：

```cpp
a = 0;
for i = M-1 → 0:
    if (index >= C(i, N)) {
        index -= C(i, N);
        a |= (1 << i);
        --N;
    }
```

这称为 **反组合数编码（unranking）**，
它可以快速得到第 b 个掩码。
