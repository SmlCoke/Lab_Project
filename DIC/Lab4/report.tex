\section{Introduction}

本实验基于PTM 16HP FinFET工艺，对两种全加器电路（16T FA和28T FA）及其构成的8位加法器链路进行了仿真与性能分析。实验主要聚焦于延迟（delay）和功耗（power）两个关键性能指标的测量与比较。

\subsection{实验全局配置}

本实验采用HSPICE进行电路仿真，仿真环境配置如下：

\begin{enumerate}
    \item 工艺库：PTM 16HP FinFETs
    \item 仿真等级：RUNLVL = 6
    \item 栅极长度：$L_g = 20$nm
    \item 供电电压：$V_{\text{DD}} = 0.75$V
    \item 仿真温度：$T = 25^\circ\mathrm{C}$
\end{enumerate}

\subsection{全加器电路设计}

实验中使用了两种不同的全加器电路设计：

\subsubsection{16T全加器（FA16）}

16T全加器采用传输门（pass transistor）逻辑，共使用16个晶体管，具有较低的晶体管数量，但可能在某些输入模式下性能不及28T全加器。其逻辑表达式为：

\begin{align}
\text{Sum} &= A \oplus B \oplus C_{\text{in}} \\
C_{\text{out}} &= (A \oplus B) \cdot C_{\text{in}} + (A \odot B) \cdot A
\end{align}

其中$\oplus$表示XOR运算，$\odot$表示XNOR运算。

\subsubsection{28T全加器（FA28）}

28T全加器采用标准CMOS逻辑门设计，共使用28个晶体管（包括2个反相器），具有更对称的上拉网络（PUN）和下拉网络（PDN），理论上具有更好的噪声容限和更均衡的延迟特性。其逻辑表达式为：

\begin{align}
C_{\text{out}} &= AB + (A+B) \cdot C_{\text{in}} \\
\text{Sum} &= ABC_{\text{in}} + \overline{C_{\text{out}}}(A + B + C_{\text{in}})
\end{align}

\section{Task 1: 全加器性能分析}

\subsection{电路搭建}

Task 1中分别对16T全加器（FA16）和28T全加器（FA28）进行了性能测试。每个全加器的输入端（A、B）通过buffer与激励源连接，输出端（Sum、Cout）各连接一个尺寸为2的反相器作为负载。

\subsection{激励源和输入模式说明}

\subsubsection{延迟仿真输入模式}

为了全面测量全加器的延迟特性，实验对所有可能的输入转换进行了仿真。延迟测量包括：

\textbf{1. 输入到Sum的延迟}（每个输入信号4种模式，共12种）：
\begin{itemize}
    \item A $\rightarrow$ Sum：固定B和$C_{\text{in}}$的4种组合（00, 01, 10, 11），A从0到1跳变
    \item B $\rightarrow$ Sum：固定A和$C_{\text{in}}$的4种组合，B从0到1跳变
    \item $C_{\text{in}}$ $\rightarrow$ Sum：固定A和B的4种组合，$C_{\text{in}}$从0到1跳变
\end{itemize}

\textbf{2. 输入到$C_{\text{out}}$的延迟}（每个输入信号2种模式，共6种）：
\begin{itemize}
    \item A $\rightarrow$ $C_{\text{out}}$：001$\rightarrow$101和010$\rightarrow$110
    \item B $\rightarrow$ $C_{\text{out}}$：100$\rightarrow$110和001$\rightarrow$011
    \item $C_{\text{in}}$ $\rightarrow$ $C_{\text{out}}$：100$\rightarrow$101和010$\rightarrow$011
\end{itemize}

每种模式下测量$t_{\text{pLH}}$（低到高传播延迟）和$t_{\text{pHL}}$（高到低传播延迟），并计算平均延迟$t_{\text{p}} = (t_{\text{pLH}} + t_{\text{pHL}})/2$。

\subsubsection{功耗仿真输入模式}

功耗仿真采用动态激励模式，三个输入端（A、B、$C_{\text{in}}$）施加周期性脉冲信号，频率相同但相位不同，使电路在运行过程中产生动态功耗。通过HSPICE的功耗分析命令测量电路的平均功耗。

\subsection{面积计算}

电路面积以晶体管数量为度量标准。根据HSPICE子电路定义：

\textbf{FA16面积}：
\begin{itemize}
    \item 核心逻辑电路：16个晶体管（8个NMOS + 8个PMOS）
    \item 反相器（用于生成$\overline{B}$和$\overline{A \oplus B}$）：2个反相器 $\times$ 2 = 4个晶体管
    \item \textbf{总计}：16 + 4 = \textbf{20个晶体管}
\end{itemize}

\textbf{FA28面积}：
\begin{itemize}
    \item Carry模块：10个晶体管（5个NMOS + 5个PMOS）
    \item Sum模块：14个晶体管（7个NMOS + 7个PMOS）
    \item 反相器（Cout和Sum输出）：2个反相器 $\times$ 2 = 4个晶体管
    \item \textbf{总计}：10 + 14 + 4 = \textbf{28个晶体管}
\end{itemize}

\section{Task 2: 8位加法器链路性能分析}

\subsection{电路搭建}

Task 2构建了两种8位加法器链路：
\begin{itemize}
    \item \textbf{Adder1}：由8个FA28串联组成
    \item \textbf{Adder2}：由4个FA28和4个FA16交替排列组成（位置：FA28-FA16-FA28-FA16-FA28-FA16-FA28-FA16）
\end{itemize}

每个全加器单元都包含输入buffer（用于隔离输入端），以及输出负载（尺寸为2的反相器）。链路中，前一级的进位输出$C_{\text{out}}$连接到后一级的进位输入$C_{\text{in}}$。

\subsection{激励源和输入模式说明}

\subsubsection{延迟仿真输入模式}

延迟仿真测量从$C_0$（初始进位输入）到两个关键输出的传播延迟：
\begin{itemize}
    \item $C_0 \rightarrow C_{\text{out}}$（最终进位输出）：测量进位信号沿链路传播的延迟
    \item $C_0 \rightarrow S_7$（最高位和输出）：测量进位信号影响最高位和输出的延迟
\end{itemize}

输入条件：A[7:0] = 11111111（全1），B[7:0] = 00000000（全0），$C_0$施加脉冲激励。这种输入模式确保进位信号需要通过所有8级全加器传播。

\subsubsection{功耗仿真输入模式}

功耗仿真采用4种不同的输入激励模式（pattern1-4），通过改变A和B的输入值以及$C_0$的激励方式，测量不同工作场景下的功耗。

\subsection{面积计算}

\textbf{Adder1面积}：
\begin{itemize}
    \item 8个FA28单元：8 $\times$ 28 = 224个晶体管
    \item 8个输入buffer（每个FA28的A、B各一个buffer，每个buffer = 2个反相器 = 4个晶体管）：8 $\times$ 2 $\times$ 4 = 64个晶体管
    \item 8个输出负载反相器（Sum输出，每个2个晶体管）：8 $\times$ 2 = 16个晶体管
    \item \textbf{总计}：224 + 64 + 16 = \textbf{304个晶体管}
\end{itemize}

\textbf{Adder2面积}：
\begin{itemize}
    \item 4个FA28单元：4 $\times$ 28 = 112个晶体管
    \item 4个FA16单元：4 $\times$ 20 = 80个晶体管
    \item 8个输入buffer：8 $\times$ 2 $\times$ 4 = 64个晶体管
    \item 8个输出负载反相器：8 $\times$ 2 = 16个晶体管
    \item \textbf{总计}：112 + 80 + 64 + 16 = \textbf{272个晶体管}
\end{itemize}

Adder2由于使用了部分FA16（20个晶体管/单元），相比Adder1（全FA28）节省了32个晶体管，面积减少约10.5\%。

    \item Adder2的延迟不均衡性更明显（$t_{\text{pLH}}$与$t_{\text{pHL}}$差异较大），这是由于FA16和FA28混合使用导致的延迟不匹配

\section{结论}

通过本次实验，我们对16T全加器和28T全加器以及它们组成的8位加法器链路进行了全面的性能分析：

\begin{enumerate}
    \item \textbf{单级全加器性能}：
    \begin{itemize}
        \item FA16在平均延迟上略优于FA28（9.76ps vs 13.48ps），但延迟分布不均衡
        \item FA28具有更均衡的延迟特性，各路径延迟差异较小
        \item FA16的面积（20个晶体管）小于FA28（28个晶体管），面积节省约28.6\%
    \end{itemize}
    
    \item \textbf{8位加法器链路性能}：
    \begin{itemize}
        \item 全FA28设计（Adder1）在进位传播路径上表现更优，延迟为102.50ps
        \item FA28+FA16交替设计（Adder2）虽然节省了面积（272 vs 304个晶体管，减少10.5\%），但延迟增加到109.40ps
        \item 在链路设计中，延迟均衡性和稳定性比单级速度优势更重要
    \end{itemize}
    
    \item \textbf{设计权衡}：
    \begin{itemize}
        \item 若优先考虑性能，全FA28设计是更好的选择
        \item 若优先考虑面积和功耗，可以考虑混合设计，但需要仔细权衡性能损失
        \item 实际应用中需根据具体需求（性能、面积、功耗）选择合适的设计方案
    \end{itemize}
\end{enumerate}
