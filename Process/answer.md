# 集成电路工艺技术基础 期末测试解答

## 1. (17分) 硅晶圆的干法热氧化过程

### 1) 推算生长20nm的SiO₂需要消耗多少厚度的Si?

在热氧化过程中，硅转化为二氧化硅时体积会膨胀。通常，每消耗1单位厚度的硅，会产生约2.25单位厚度的SiO₂。这是因为Si原子(原子量28.09，密度2.33g/cm³)与氧结合形成SiO₂(分子量60.08，密度2.2g/cm³)，体积增大。

因此，生长20nm的SiO₂需要消耗的Si厚度为：
- 消耗Si厚度：$ \dfrac{20\,\text{nm}}{2.25} \approx 8.89\,\text{nm} $

即约$8.9\,\text{nm}$的硅被消耗。

### 2) 在裸硅表面生长20nm的SiO₂，1000℃条件下需要多长时间?

根据题目提供的参数：
- $C = 7.72\times 10^{2}\ \mu\text{m}^2/\text{hr}$
- $E_1 = 1.23\ \text{eV}$
- $C_2 = 6.23\times 10^{6}\ \mu\text{m}/\text{hr}$
- $E_2 = 2.0\ \text{eV}$
- $k = 8.62\times 10^{-5}\ \text{eV/K}$
- $T = 1000^\circ\text{C} = 1273\ \text{K}$

计算1000℃下的 $B$ 和 $B/A$：
- $B = C \cdot e^{-E_1/(kT)} = 7.72\times 10^{2} \times e^{-1.23/(8.62\times 10^{-5}\times 1273)} \approx 0.0105\ \mu\text{m}^2/\text{hr}$
- $\dfrac{B}{A} = C_2 \cdot e^{-E_2/(kT)} = 6.23\times 10^{6} \times e^{-2.0/(8.62\times 10^{-5}\times 1273)} \approx 0.0797\ \mu\text{m}/\text{hr}$

对于薄氧化层（$20\,\text{nm} = 0.02\,\mu\text{m}$），在初始阶段氧化速率由线性速率常数 $B/A$ 控制：
- $x \approx (B/A)\,t$
- $t = \dfrac{x}{B/A} = \dfrac{0.02}{0.0797} \approx 0.251\ \text{hr} \approx 15.06\ \text{分钟}$

因此，在裸硅表面生长20nm的SiO₂需要约 $15.1$ 分钟。

### 3) 如果硅表面预先生长200nm的SiO₂，1000℃条件又新生长20nm的SiO₂，说明整个过程生长速率如何变化，估算总时间为多长?

当表面已有$200\,\text{nm}$（$0.2\,\mu\text{m}$）氧化层时，氧化过程进入抛物线速率控制区。使用Deal-Grove模型：
- $x^{2} + A x = B\,(t + \tau)$

首先计算参数 $A$：
- $A = \dfrac{B}{B/A} = \dfrac{0.0105}{0.0797} \approx 0.132\ \mu\text{m}$

计算初始时间 $\tau$（当 $x_0 = 0.2\,\mu\text{m}$）：
- $x_0^{2} + A x_0 = B\,\tau$
- $(0.2)^2 + 0.132 \times 0.2 = 0.0105\,\tau$
- $0.04 + 0.0264 = 0.0105\,\tau$
- $\tau \approx \dfrac{0.0664}{0.0105} \approx 6.32\ \text{hr}$

计算生长到 $0.22\,\mu\text{m}$（增加$20\,\text{nm}$）所需的总时间：
- $(0.22)^2 + 0.132 \times 0.22 = 0.0105\,t_{\text{total}}$
- $0.0484 + 0.02904 = 0.0105\,t_{\text{total}}$
- $t_{\text{total}} \approx \dfrac{0.07744}{0.0105} \approx 7.375\ \text{hr}$

因此，生长额外$20\,\text{nm}$ SiO₂所需的时间为：
- $t = t_{\text{total}} - \tau = 7.375 - 6.32 \approx 1.055\ \text{hr} \approx 63.3\ \text{分钟}$

**生长速率变化**：初始$200\,\text{nm}$氧化层生长较快（受线性速率控制），新增$20\,\text{nm}$氧化层生长较慢（受抛物线速率控制），因为氧气需要穿过已有的厚氧化层扩散到Si/SiO₂界面。这表明在已有厚氧化层的情况下，氧化速率显著降低。

## 2. (18分) P型掺杂衬底上形成N阱

### 1) 磷离子注入分布图

离子注入的分布通常符合高斯分布：
- $N(x) = \dfrac{Q}{\sqrt{2\pi}\,\Delta R_p} \exp\!\Big( -\dfrac{(x-R_p)^2}{2(\Delta R_p)^2} \Big)$

其中：
- $Q = 1\times 10^{18}\ \text{atoms}/\text{cm}^2$
- $R_p = 50\,\text{nm} = 0.05\,\mu\text{m}$
- $\Delta R_p = 20\,\text{nm} = 0.02\,\mu\text{m}$

峰值浓度在 $x = R_p = 50\,\text{nm}$ 处：
- $N_{\max} = \dfrac{1\times 10^{18}}{\sqrt{2\pi}\times 0.02} \approx 2\times 10^{19}\ \text{atoms}/\text{cm}^3$

在表面（$x=0$）处的浓度：
- $N(0) = \dfrac{1\times 10^{18}}{\sqrt{2\pi}\times 0.02} \exp\!\Big(-\dfrac{(0-0.05)^2}{2\times (0.02)^2}\Big)$
- $= 2\times 10^{19} \times e^{-3.125} \approx 8.8\times 10^{17}\ \text{atoms}/\text{cm}^3$

分布图特点：
- 以 $50\,\text{nm}$ 深度为中心呈高斯分布
- 表面浓度约为峰值的 $4.4\%$
- 随深度增加，浓度先上升至 $50\,\text{nm}$ 达到峰值，然后逐渐下降
- $100\,\text{nm}$ 深度处的浓度约为峰值的 $4.4\%$
- $150\,\text{nm}$ 深度处的浓度接近于 $0$

### 2) 推阱过程中的磷掺杂分布

在推阱过程中，磷原子会从注入分布向深处扩散。使用扩散方程：
- $N(x,t) = \dfrac{Q}{\sqrt{4\pi\,(D t + (\Delta R_p)^2)}} \exp\!\Big( -\dfrac{(x-R_p)^2}{4\,(D t + (\Delta R_p)^2)} \Big)$

其中 $D = 1\times 10^{-13}\ \text{cm}^2/\text{s} = 3.6\times 10^{-6}\ \text{cm}^2/\text{hr}$。

**对于 $t = 1\,\text{h}$：**
- $D t = 3.6\times 10^{-6}\ \text{cm}^2$
- $(\Delta R_p)^2 = (2\times 10^{-6})^2 = 4\times 10^{-12}\ \text{cm}^2$
- $D t + (\Delta R_p)^2 \approx 3.6\times 10^{-6}\ \text{cm}^2$

分布较窄，主要集中在表面附近 $50$–$100\,\text{nm}$ 深度，峰值在 $50\,\text{nm}$ 附近，浓度约 $1.5\times 10^{18}\ \text{atoms}/\text{cm}^3$。

**对于 $t = 3\,\text{h}$：**
- $D t = 1.08\times 10^{-5}\ \text{cm}^2$

分布变宽，延伸至约 $1$–$1.5\,\mu\text{m}$ 深度，峰值浓度降至约 $8.5\times 10^{17}\ \text{atoms}/\text{cm}^3$，峰值位置略微向深处移动。

**对于 $t = 5\,\text{h}$：**
- $D t = 1.8\times 10^{-5}\ \text{cm}^2$

分布进一步加宽，延伸至约 $2\,\mu\text{m}$ 深度，峰值浓度约 $6.6\times 10^{17}\ \text{atoms}/\text{cm}^3$。

**5h推阱时间是否足够：**

要判断 $5\,\text{h}$ 是否足够达到 $3\,\mu\text{m}$ 结深，需计算 $3\,\mu\text{m}$ 处的浓度：
- $N(3\,\mu\text{m}, 5\,\text{h}) \approx 6.62\times 10^{17} \times \exp\!\Big(-\dfrac{(3-0.05)^2}{0.7216}\Big) \approx 4.3\times 10^{16}\ \text{atoms}/\text{cm}^3$

衬底掺杂浓度为 $1\times 10^{16}\ \text{atoms}/\text{cm}^3$，$3\,\mu\text{m}$ 处浓度（$4.3\times 10^{16}$）仍高于衬底浓度，结深大于 $3\,\mu\text{m}$。因此，**$5\,\text{h}$ 推阱时间足够**达到 $3\,\mu\text{m}$ 结深。

## 3. (15分) 干法刻蚀和湿法刻蚀

### 1) 二者基本原理及各自的优缺点

**湿法刻蚀**：
- **基本原理**：将晶圆浸泡在化学溶液中，通过化学反应选择性地溶解不需要的材料。例如，HF溶液刻蚀SiO₂，KOH溶液刻蚀Si。
- **优点**：
  1. 高选择性：对不同材料的刻蚀速率差异大
  2. 低成本：设备简单，操作容易
  3. 无等离子体损伤：不会对器件表面造成离子损伤
  4. 均匀性好：批量处理时均匀性较佳
- **缺点**：
  1. 各向同性：无法实现垂直侧壁，会产生undercut
  2. 分辨率低：不适合小特征尺寸（< $1\,\mu\text{m}$）工艺
  3. 环境问题：使用和处理腐蚀性化学品
  4. 颗粒污染：反应产物可能形成颗粒
  5. 难以自动化：批次处理，难以实现单片控制

**干法刻蚀**：
- **基本原理**：使用等离子体中的活性离子和自由基，在真空腔室中通过物理和/或化学作用去除材料。常用方法包括反应离子刻蚀(RIE)、离子束刻蚀等。
- **优点**：
  1. 各向异性：可实现垂直侧壁，高分辨率
  2. 良好的均匀性：晶圆表面刻蚀均匀
  3. 适用于小特征尺寸：现代IC制造必需
  4. 易于控制：工艺参数可精确调控
  5. 清洁：无液体化学品，减少污染
  6. 可自动化：适合单片处理，与现代生产线兼容
- **缺点**：
  1. 选择性较低：相比湿法刻蚀
  2. 高成本：设备复杂，维护费用高
  3. 表面损伤：离子轰击可能导致晶格损伤
  4. 操作复杂：需要专业人员操作
  5. 副产物可能形成聚合物，影响刻蚀质量

### 2) 二者刻蚀速度的影响因素

**湿法刻蚀速度的影响因素**：
1. **温度**：温度升高，反应速率加快，刻蚀速率增加。通常温度每升高 $10^\circ\text{C}$，速率增加 $2$–$3$ 倍
2. **溶液浓度**：适当增加反应物浓度可提高刻蚀速率，但过高可能降低选择性
3. **搅拌/流动**：提高溶液流动可加速反应物传输和产物移除，提高刻蚀速率
4. **材料特性**：
   - 晶向：如Si在KOH中 $(100)$ 晶面刻蚀速率比 $(111)$ 快约 $100$ 倍
   - 掺杂浓度：重掺杂区域刻蚀速率通常较低
5. **表面状态**：氧化层、污染等会影响初始刻蚀速率

**干法刻蚀速度的影响因素**：
1. **气体组成**：不同气体产生不同活性物种，影响化学刻蚀速率
2. **气体流量**：影响反应物供应和产物移除
3. **气压**：
   - 低压（$1$–$10\,\text{mTorr}$）：离子平均自由程长，各向异性好，但速率可能低
   - 高压（$10$–$100\,\text{mTorr}$）：等离子体密度高，但各向异性差
4. **RF功率**：影响离子能量和等离子体密度，增加功率通常提高刻蚀速率
5. **衬底温度**：影响表面反应速率和产物脱附
6. **电极配置**：影响电场分布和离子能量
7. **自偏压**：影响离子轰击能量
8. **微负载效应**：密集区域比稀疏区域刻蚀速率低

## 4. (12分) CMOS器件前道工艺中的薄膜沉积

### 氧化硅(SiO₂)的用途及沉积方法
- **用途**：
  1. 栅极氧化层
  2. 隔离层（STI填充氧化物）
  3. 侧墙(Spacer)
  4. 钝化层
  5. 层间介质
- **沉积方法**：
  1. **热氧化**：Si + O₂ → SiO₂（干法）或 Si + H₂O → SiO₂（湿法），$900$–$1100^\circ\text{C}$
  2. **CVD**：
     - APCVD：TEOS + O₂，$400$–$450^\circ\text{C}$
     - LPCVD：TEOS 或 SiH₄+O₂，$650$–$750^\circ\text{C}$
     - PECVD：SiH₄+N₂O 或 TEOS+O₃，$300$–$400^\circ\text{C}$
  3. **HDP-CVD**：用于STI填充

### 氮化硅(Si₃N₄)的用途及沉积方法
- **用途**：
  1. 阻挡层
  2. 应力膜
  3. 侧墙
  4. CMP停止层
  5. 钝化层
- **沉积方法**：
  1. LPCVD：SiH₂Cl₂ + NH₃，$700$–$800^\circ\text{C}$
  2. PECVD：SiH₄ + NH₃，$300$–$400^\circ\text{C}$
  3. 热CVD：其他硅源/氮源

### 多晶硅(Poly-Si)的用途及沉积方法
- **用途**：
  1. 栅电极
  2. 互连
  3. 电阻
  4. 电容器电极
  5. 硅化阻挡层
- **沉积方法**：
  1. LPCVD：SiH₄，$580$–$650^\circ\text{C}$
  2. APCVD：SiH₄ 或 Si₂H₆，速率快但均匀性差
  3. PECVD：低温，质量略低

## 5. (27分) 光刻分辨率与焦深

### (1) 如何在提高图形分辨率的同时不减少焦深，举例说明

在光刻中，分辨率（$R$）和焦深（$DOF$）通常是一对矛盾。瑞利公式：

- $R = k_1 \dfrac{\lambda}{NA}$
- $DOF = k_2 \dfrac{\lambda}{NA^{2}}$

其中 $\lambda$ 是波长，$NA$ 是数值孔径，$k_1,k_2$ 为工艺常数。

提高 $NA$ 可提高分辨率，但会降低焦深（与 $NA^2$ 成反比）。为了在提高分辨率的同时不减少焦深，可用：

1. **减小波长 $\lambda$**：如从 i-line ($365\,\text{nm}$) → KrF ($248\,\text{nm}$) → ArF ($193\,\text{nm}$) → EUV ($13.5\,\text{nm}$)。
2. **减小 $k_1$（RET）**：相移掩模、OPC、离轴照明等可将 $k_1$ 降至约 $0.3$。
3. **浸没式光刻**：水折射率 $n\approx 1.44$，有效 $NA = n\sin\theta > 1$，193nm浸没式可实现 $\sim 38\,\text{nm}$ 分辨率且焦深可接受。
4. **多重图形**：双重/四重曝光，自对准双重图形(SADP)等提升有效分辨率而不过分压缩单次焦深。
5. **计算光刻优化**：SMO、ILT 提升有效分辨率，焦深基本不变。

### (2) DOF Implications问题

若 $DOF < \Delta$（晶圆表面高度变化），则部分区域离焦，产生线宽变化、图形模糊甚至缺陷，良率下降。

改进措施：
1. **增加焦深**：降低 $NA$（牺牲分辨率），或优化工艺降低 $k_2$，如厚胶工艺。
2. **减小 $\Delta$**：CMP 全局平坦化，优化前序膜厚与形貌；分区曝光、多点对焦/实时动态对焦。
3. **先进光刻技术**：浸没式、EUV、多重曝光等。
4. **工艺流程调整**：将焦深敏感层放在更平坦区域，关键层前增加CMP。
5. **对焦技术**：多点测高、扫描过程动态调焦（如 $13\times 13$ 点测高实现纳米级对焦）。

最实用的是结合CMP降低 $\Delta$，并用先进对焦确保 $\Delta < DOF$。

## 6. (11分) CMOS使用high-k介质和金属栅的原因

### High-k介质和金属栅的原因和优势

随着CMOS尺寸缩小，传统SiO₂栅介质厚度接近极限（$1$–$2\,\text{nm}$），出现：

1. **栅极漏电流剧增**：量子隧穿 $J \propto e^{-\beta t_{\text{ox}}}$，$t_{\text{ox}}<2\,\text{nm}$ 时漏电飙升。
2. **多晶硅耗尽效应**：阈值偏移 $\Delta V_{\text{th}} \approx Q_{\text{dep}}/C_{\text{ox}}$，等效栅厚增大。
3. **硼穿透**：P型多晶硅中的B穿透超薄SiO₂导致阈值漂移。

**High-k 介质**（如 HfO₂、ZrO₂，$k\approx 20$–$25$）优势：
- 等效氧化层厚度 $EOT = t_{\text{high-k}} \dfrac{k_{\text{SiO2}}}{k_{\text{high-k}}}$。例：$1.5\,\text{nm}$ HfO₂（$k=25$）等效 $0.5\,\text{nm}$ SiO₂。
- 较厚物理厚度显著降低隧穿漏电（漏电随物理厚度指数下降）。

**金属栅极**（TiN、TaN、TiAlC 等）优势：
- 消除多晶硅耗尽（金属无耗尽层）。
- 功函数可调：NMOS 用低功函数（金属 $\sim 4.1\,\text{eV}$），PMOS 用高功函数（$\sim 5.0\,\text{eV}$），便于阈值控制。
- 无硼穿透问题。

**总体优势**：
- 漏电降低 $10$–$100$ 倍，静态功耗显著下降
- 有效EOT减小，驱动电流提升
- 阈值控制更好，可靠性提高

### 互连布线间的绝缘层为何使用低k介质?

互连延迟 $\tau = R C$，其中 $C = k\,\varepsilon_0\,A/d$。降低介电常数 $k$ 可直接减小 $C$，带来：

1. **延迟降低**：低k（$k<3.0$，如 SiCOH $k=2.7$–$3.0$，超低k $k<2.5$）可使互连电容降低 $20$–$50\%$，延迟下降。
2. **功耗降低**：动态功耗 $P_{\text{dyn}} = \alpha C V^2 f$，降低 $C$ 直接降功耗。
3. **串扰减小**：寄生电容减小降低线间串扰。

例如在 $28\,\text{nm}$ 工艺中使用 $k=2.7$ 低k介质，相比传统 SiO₂（$k=4.0$），互连延迟约降 $30\%$，功耗降约 $25\%$。

总结：High-k/金属栅解决超薄栅介质下的漏电与多晶硅耗尽问题；低k介质解决互连延迟与功耗问题，二者共同支撑先进CMOS工艺。
