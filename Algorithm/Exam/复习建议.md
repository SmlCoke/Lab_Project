## 二、重点知识模块

根据两年试卷分析，课程重点可以总结如下：

### 1. 数学基础（必考，约8-10分）

**重点内容：**
- **主定理（Master Theorem）**：务必熟练掌握三种情况及扩展形式
  - 情况1: $f(n) = O(n^{\log_b a - \epsilon})$ → $T(n) = \Theta(n^{\log_b a})$
  - 情况2: $f(n) = \Theta(n^{\log_b a} \log^k n)$ → $T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$
  - 情况3: $f(n) = \Omega(n^{\log_b a + \epsilon})$ + 正则条件 → $T(n) = \Theta(f(n))$

- **渐进复杂度分析**：$O$、$\Omega$、$\Theta$ 记号的定义和使用

**复习建议：**
- 练习至少10道递归方程求解题
- 掌握主定理的三种情况及其判断方法
- 了解迭代法、递归树法等其他求解方法

---

### 2. 分治算法（重点，约12分）

**重点内容：**
- 分治策略的三个步骤：分解、递归求解、合并
- 经典问题：归并排序、快速排序、二分查找、数对计数
- 复杂度分析：通常用主定理求解

**典型题型：**
- 2022年：数对计数问题（$O(n \log n)$）
- 2023年：固定点查找问题（$O(\log n)$）

**复习建议：**
- 掌握二分查找及其变形（查找固定点、查找旋转数组中的元素等）
- 练习归并排序中的变形问题（逆序对、数对统计等）
- 理解分治算法的递归方程及其求解

---

### 3. 贪心算法（重点，约11分）

**重点内容：**
- 贪心选择性质的证明（交换论证、反证法）
- 最优子结构的证明
- 常见贪心问题：活动选择、任务调度、哈夫曼编码

**典型题型：**
- 2022年：订单调度问题（按截止时间排序）
- 2023年：加油站问题（尽可能走远）

**复习建议：**
- **重点掌握证明方法**：贪心选择性质和最优子结构
- 练习证明题：通过交换论证证明贪心策略的正确性
- 理解贪心算法与动态规划的区别

---

### 4. 动态规划（重点，约14分）

**重点内容：**
- 动态规划四要素：状态定义、递推方程、边界条件、计算顺序
- 最优子结构的识别
- 状态转移方程的建立
- 空间优化（滚动数组）

**典型题型：**
- 2022年：网格路径问题（二维DP）
- 2023年：礼品分配问题（子集和问题，背包变形）

**复习建议：**
- **重点练习状态定义和递推方程的建立**
- 掌握经典DP问题：背包问题、最长公共子序列、编辑距离、矩阵链乘法
- 练习空间优化技巧
- 理解DP与贪心、分治的区别

---

### 5. 摊销分析（必考，约7分）

**重点内容：**
- 三种分析方法：聚集法、记账法、势能法
- 动态表扩张/收缩问题
- 摊销复杂度与渐进复杂度的区别

**典型题型：**
- 2022年：特定操作序列的摊销分析
- 2023年：表扩张问题及改进方案（避免抖动）

**复习建议：**
- **重点掌握势能法**（最灵活、最常用）
- 理解表扩张/收缩问题中的抖动现象及解决方案
- 练习使用三种方法分析同一问题

---

### 6. 随机算法（约8分）

**重点内容：**
- 拉斯维加斯算法 vs 蒙特卡洛算法
- 随机算法的概率分析
- 常见随机算法：快速排序的随机化、Miller-Rabin素数测试

**典型题型：**
- 2022年：拉斯维加斯算法（随机采样找1）
- 2023年：蒙特卡洛算法（素数测试）

**复习建议：**
- 理解两类随机算法的区别：
  - 拉斯维加斯：结果总是正确，运行时间随机
  - 蒙特卡洛：运行时间确定，结果可能错误
- 掌握概率分析方法
- 熟悉Miller-Rabin素数测试算法

---

### 7. 近似算法（约9分）

**重点内容：**
- 近似比的定义和计算
- 近似算法的性能分析
- 常见近似问题：顶点覆盖、旅行商问题、集合覆盖、并行调度

**典型题型：**
- 2022年：顶点覆盖问题（2-近似算法）
- 2023年：最短并行调度问题（LPT算法，3/2-近似）

**复习建议：**
- **重点掌握近似比的证明方法**
- 理解最优解的下界估计
- 练习几个经典近似算法及其分析

---

### 8. NP问题（重点，约10-15分）

**重点内容：**
- P、NP、NP-Hard、NP-Complete的定义和关系
- 多项式时间归约
- 经典NPC问题：SAT、哈密尔顿回路、旅行商问题、背包问题

**典型题型：**
- 2022年：NPC问题的定义（概念题）
- 2023年：NP-hard的定义，判断问题类型（最长路径问题）

**复习建议：**
- **准确理解四个类的定义和关系**
- 掌握常见NPC问题及其归约关系
- 理解为什么某些问题是NP-Hard但不是NPC

---

### 9. 现代优化算法（约12分）

**重点内容：**
- 遗传算法：编码、适应度、选择、交叉、变异
- 模拟退火：接受准则、温度调度、邻域操作
- 算法设计要针对具体问题

**典型题型：**
- 2022年：遗传算法（门级网表优化）
- 2023年：模拟退火（最长路径问题）

**复习建议：**
- 理解遗传算法和模拟退火的基本框架
- **重点：针对具体问题设计编码方案、邻域操作等**
- 不要只背标准框架，要能结合问题进行设计

## 三、复习策略建议

### 1. 时间分配（按重要性）

**第一优先级（60%时间）：**
- 动态规划（14分，最高分值）
- 贪心算法（11分，需要证明）
- 分治算法（12分，常考）

**第二优先级（30%时间）：**
- 数学基础（主定理必考）
- 摊销分析（必考）
- 近似算法（证明较难）

**第三优先级（10%时间）：**
- 随机算法（相对简单）
- 现代优化算法（套用框架）

---

### 2. 学习方法建议

#### 理论类题目（概念题、定义题）
- **主定理**：熟记三种情况，练习判断
- **NP理论**：准确记忆定义，理解类之间的关系
- **摊销分析**：理解三种方法的思想

#### 证明类题目（贪心、近似算法）
- **贪心算法证明**：
  1. 贪心选择性质：通常用交换论证
  2. 最优子结构：递归定义
  
- **近似算法证明**：
  1. 找最优解的下界
  2. 分析算法输出的上界
  3. 计算比值

#### 设计类题目（DP、分治、算法设计）
- **动态规划**：
  1. 明确状态定义（最关键）
  2. 写出递推方程
  3. 确定边界条件
  4. 分析复杂度
  
- **分治算法**：
  1. 描述分解方法
  2. 说明合并策略
  3. 写出递归方程
  4. 用主定理求解复杂度

- **现代优化算法**：
  1. 针对问题设计编码方案
  2. 定义目标函数
  3. 设计邻域操作/交叉变异
  4. 套用基本框架

**进阶练习（选做）：**

3. NP问题：练习问题归约、判断问题类型

### 4. 考试技巧

#### 时间管理
- 概念题：快速作答（15分钟）
- 递归方程：熟练应用主定理（10分钟）
- 证明题：认真思考，写清楚步骤（20-30分钟）
- 算法设计题：先写思路，再写伪代码（每题20-25分钟）

#### 答题规范
1. **伪代码要求**：
   - 使用清晰的缩进
   - 关键步骤添加注释
   - 变量命名有意义

2. **分析要求**：
   - 复杂度分析要写递归方程
   - 证明要分步骤，逻辑清晰
   - 结论要明确

3. **检查要点**：
   - DP的边界条件是否正确
   - 贪心的证明是否完整
   - 复杂度分析是否正确

## 四、重点知识速查表

### 主定理速查

```
T(n) = aT(n/b) + f(n)

计算: n^(log_b a)

情况1: f(n) = O(n^(log_b a - ε)) → T(n) = Θ(n^(log_b a))
情况2: f(n) = Θ(n^(log_b a) log^k n) → T(n) = Θ(n^(log_b a) log^(k+1) n)
情况3: f(n) = Ω(n^(log_b a + ε)) 且满足正则条件 → T(n) = Θ(f(n))
```

### 常见复杂度

| 算法 | 最好 | 平均 | 最坏 | 空间 |
|------|------|------|------|------|
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) |
| 快速排序 | O(n log n) | O(n log n) | O(n²) | O(log n) |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) |

### 经典DP问题

| 问题 | 状态定义 | 复杂度 |
|------|---------|--------|
| 0-1背包 | dp[i][w] = 前i个物品，容量w的最大价值 | O(nW) |
| 完全背包 | dp[i][w] = 使用前i种物品，容量w的最大价值 | O(nW) |
| LCS | dp[i][j] = A[1..i]和B[1..j]的最长公共子序列长度 | O(mn) |
| 编辑距离 | dp[i][j] = A[1..i]变为B[1..j]的最小操作数 | O(mn) |

### NP类关系

```
P ⊆ NP
NP-Complete = NP ∩ NP-Hard
如果 P ≠ NP，则 P ∩ NP-Complete = ∅
```

## 五、易错点提醒

1. **主定理使用**
   - 注意检查是否满足正则条件（情况3）
   - 不要忽略对数项（log^k n）

2. **贪心算法证明**
   - 证明要完整：贪心选择性质 + 最优子结构
   - 交换论证要清楚说明为什么交换后不会更差

3. **动态规划**
   - 边界条件容易遗漏
   - 状态转移时注意数组下标不要越界

4. **NP问题**
   - NP-Hard 不一定在 NP 中
   - NP-Complete = NP ∩ NP-Hard

5. **摊销分析**
   - 摊销复杂度 ≠ 平均复杂度
   - 表扩张收缩阈值要分开（避免抖动）
