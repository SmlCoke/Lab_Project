\section{Introduction and background}
本项目基于逻辑努力（Logical Effort）方法对数字电路进行优化，旨在通过合理选择电路中各个逻辑门的尺寸，以最小化信号传播延迟。逻辑努力是一种通过分析电路中每个逻辑门的延迟和负载来指导电路设计的方法。

然而，理论与实际有不可避免的偏差，但是基于逻辑努力的分析方法依旧可以为我们指明一个方向。我们可以根据这一方法分析电路中各个逻辑门、晶体管的尺寸参数范围，在此基础上，借助仿真工具，通过对电路进行建模和仿真，我们可以找到最佳的门尺寸组合，从而提高电路性能。

\subsection{实验全局配置}
本实验采用HSPICE进行电路仿真，仿真环境配置如下：

\begin{enumerate}
    \item 工艺库：PTM 16HP FinFETs
    \item 仿真等级：RUNLVL = 6
    \item 栅极长度：$L_g = 20$nm
    \item 供电电压：$V_{\text{DD}} = 0.75$V
    \item 仿真温度：$T = 25^\circ\mathrm{C}$
\end{enumerate}

\subsection{逻辑门的HSPICE定义}
为了节省篇幅，这里仅给出2-NAND门的子电路定义作为示例，其余Inverter, 2-NOR, 3-NAND, 3-NOR们的子电路定义见附录。

这些逻辑门的子电路定义均采用了FinFET晶体管模型，并通过调整FinFET的fin number（NFIN参数）来改变晶体管的尺寸，从而实现对逻辑门驱动能力的调节。但是这里有一个关键问题：\textbf{晶体管的NFIN参数并不直接等于输入栅电容相对于参考反相器(NMOS, PMOS NFIN = 1)的倍数}。

以一个n-NAND为例，NFIN参数的定义与逻辑门输入栅电容的关系为：
$$S_P = CM/g$$
$$S_N = CM/g\times n$$

其中$CM$是输入栅电容相对于参考反相器的放大倍数，$g$是逻辑门的逻辑努力，$n$是逻辑门的输入数目，$S_N$和$S_P$分别是NMOS和PMOS晶体管的尺寸（即NFIN参数）。

例如，2-NAND在HSPICE中的定义代码如下：
\textbf{2-NAND}
\begin{lstlisting}
* Sub circuit: 2-NAND
* g = 1.5
* CM到SN/SP转换: SN = (CM/1.5)*2, SP = CM/1.5
.subckt NAND2 in1 in2 out vdd gnd SN=1 SP=1 Lg=20n
* PUN
Mp1 out in1 vdd vdd pfet L='Lg' NFIN='SP'
Mp2 out in2 vdd vdd pfet L='Lg' NFIN='SP'
* PDN
Mn1 out in1 source1 gnd nfet L='Lg' NFIN='SN'
Mn2 source1 in2 gnd gnd nfet L='Lg' NFIN='SN'
.ends NAND2
\end{lstlisting}

\subsection{仿真配置说明}
本次SPICE仿真过程中，有几点注意事项：

1. 由于工艺库采用的是16hp FinFET，可以近似认为相同尺寸（$W, L$）的NMOS和PMOS具有相同的电流驱动能力（即具有相同的导通电阻），因此，在构建驱动能力相同的PUN和PDN时，确保PUN和PDN在最坏情况下拥有相同的导通电阻，就是要确保在最坏情况下，PUN和PDN具有相同的等效尺寸。

2. 在1.的前提下，我们利用"NFIN"参数来评判FinFET的尺寸。但是"NFIN"只能是整数，因此，在后续组合逻辑门链优化过程中，计算出来的理论尺寸，实验中采取\textbf{四舍五入}的方式得到实际仿真使用尺寸。

3. 延时的测量方法：测量出在两种输入翻转（从高到低和从低到高）情况下，输出的$t_{\text{pHL}}$和$t_{\text{pLH}}$，然后用\textbf{平均延时}：
$$t_{\text{p}} = \frac{t_{\text{pHL}} + t_{\text{pLH}}}{2}$$
衡量该\textbf{critical path}的性能。

4. 在后续所有任务中，我们用符号：$CM$(cap multiply)代表逻辑门输入栅电容相对于参考反相器输入栅电容的倍数。用$S_N$和$S_P$代表一个逻辑门中N管和P管的尺寸。

5. 在Task2和Task3中，我们用$z_1 \sim z_m$代表插入的$m$级反相器及其尺寸。

通过\textbf{AM-GM}不等式，得到best stage effort:
$$h_{\text{opt}} = H^{1/N} = 192^{1/4} \approx 3.72$$
因此，我们从前往后，以此计算出这条链上的所有逻辑门的等效扇出以及尺寸：

1. inv(minimum size): $CM_1 = 1$, $f_1 = h_{\text{opt}}/(g_1 b_1) = 3.722/(1 \cdot 1) = 3.722$

2. 3-NAND: $CM_2 = f_1 CM_1 = 3.722, f_2 = h_{\text{opt}}/(g_2 b_2) = 3.722/(2 \cdot 1) = 1.861$

3. 2-NOR: $CM_3 = f_2 CM_2 = 6.928, f_3 = h_{\text{opt}}/(g_3 b_3) = 3.722/(3/2 \cdot 1) = 2.482$

4. inv2: $CM_4 = f_3 CM_3 = 17.193, f_4 = h_{\text{opt}}/(g_4 b_4) = 3.722/(1 \cdot 1) = 3.722$

\section{Task 2: Use Logical Effort to Optimize 4$\times$16 Decoder}

\subsection{实验电路}

本任务利用互补逻辑门搭建一个完整的4 to 16解码器。电路结构包含四层：

第一层是4个反相器，输入$A_3$, $A_2$, $A_1$, $A_0$，输出$\overline{A_3}, \overline{A_2}, \overline{A_1}, \overline{A_0}$（我们分别记为：$NA_3$, $NA_2$, $NA_1$, $NA_0$）；

第二层是4个反相器，输出$\overline{\overline{A_3}}, \overline{\overline{A_2}}, \overline{\overline{A_1}}, \overline{\overline{A_0}}$（我们分别记为：$PA_3$, $PA_2$, $PA_1$, $PA_0$）；

第三层是8个NAND2门，实现$\{PA_3, NA_3\}$和$\{PA_2, NA_2\}$的笛卡尔积、以及$\{PA_1, NA_1\}$和$\{PA_0, NA_0\}$的笛卡尔积；这两组笛卡尔积会分别预编码：$\bar{A_3}\bar{A_2} \rightarrow A_{3}A_{2}$以及$\bar{A_1}\bar{A_0} \rightarrow A_{1}A_{0}$。

最后一层是16个NOR2门，输出word0到word15。负载电容等效于128倍最小反相器尺寸的反相器。

\subsection{critical path}

由图\ref{fig:task2_circuit}不难发现，电路中的所有关键路径种类相同，即都经过了两级反相器、一级2-NAND以及以及2-NOR门，共8条。因此我们选择其中任意一条critical path讨论即可。这里选择了：

$A_3 \rightarrow \text{Xinv31} \rightarrow \text{NA}_3 \rightarrow \text{Xinv32} \rightarrow \text{PA}_3 \rightarrow \text{XNAND2\_7} \rightarrow \text{PA3\_PA2} \rightarrow \text{XNOR2\_15} \rightarrow \text{word}15 \rightarrow \text{Cload}(128\times{inv})$。

其中Xinv31、Xinv32是$A_3$经过的第一、二级反相器，\textbf{在本实验中均为最小反相器。}XNAND2\_7是$PA_3$经过的其中一个2-NAND门，XNOR2\_15是信号$PA3\_PA2$（即信号$A_{3}A_{2}$）经过的2-NOR门。

优化目标是考察从电路中第一级反相器Xinv31的输出结点（即案例中的$NA_3$）到负载电容输入结点的最小延迟，优化方法是在$\text{word}15$和负载电容间插入多级反相器作为缓冲。

\subsection{理论优化阶段}

\subsubsection{critical path延迟函数的极值求解}

我们从已知组合逻辑门能够获取的指标（本征延迟$p$、逻辑努力$g$、电容倍数$CM$、等效扇出$f$、分支努力$b$）参见表\ref{tab:task2_metrics}（设Xinv32, XNAND2\_7, XNOR2\_15的参数下标分别为1, 2, 3, 4，$z_1 \sim z_m$分别代表插入的$m$级反相器）

\begin{table}[htbp]

因此我们有路径努力：
$$H_1 = x_1 + 16y + 16\frac{y}{x_1} + \frac{2z_1}{y} + \frac{z_2}{z_1} + \frac{z_3}{z_2} \cdots + \frac{z_m}{z_{m-1}} + \frac{256}{z_m}$$

这是一个\textbf{连续-离散混合多元函数求极值问题}，我们先不考虑晶体管实际尺寸必须为整数，即我们在优化时先认为除了$m$必须为整数外，其余变量$x_1, y, z_1, z_2, \cdots z_m$可以为正实数。在这种情况下，我们求该函数的极值点，具体数学分析如下：

\begin{enumerate}
    \item 对于反相器链$z_1 \sim z_m$中的变量求偏导：
    
    $$\frac{\partial H_1}{\partial z_k}=0\quad (2\le k\le m-1)$$

    可得递推关系：
    \[
    z_{k+1}=\frac{z_k^2}{z_{k-1}}
    \]
    本质上，这是\textbf{AM-GM}不等式的偏导解法，有：
    \[
    z_{k+1} = z_{k}q, \qquad k \geq 1, q>0
    \]

    由末端反相器条件$\partial H_1/\partial z_m=0$：
    \[
    z_m^2 = 256, z_{m-1}\quad\Rightarrow\quad z_1 q^{m}=256 \quad\Rightarrow\quad z_1=\frac{256}{q^{m}}
    \]
    由起始反相器条件$\partial H_1/\partial z_1=0$：
    \[
    q=\frac{2z_1}{y}.
    \]
    联立可得
    \[
    y=\frac{512}{q^{m+1}}.
    \]

    \item 对$x_1$求偏导：$\partial H_1/\partial x_1=0$给出：
    
    \[
    x_1=4\sqrt{y},
    \]

    将以上代回$H_1$，可以把原问题化简为在\textbf{固定整数}下关于单一正变量$q$最小值问题：
    \[
    H(q;m)=\frac{8192}{q^{,m+1}}+\frac{128\sqrt{2}}{q^{(m+1)/2}}+(m+1)q
    \]

    \item 直到这里，我们还没有利用极值点条件：$\partial H_1/\partial y=0$，而是选择了直接将变量$y$代换掉，将原函数$H_1$化简为单变量$q_1$的函数，好处就是接下来我们会在不同整数$m$值下对这个单变量函数直接求导（数学上可以证明，此时求导的效果等价于$\partial H_1/\partial y=0$，证明从略）：

    $$\frac{\partial H(q;m)}{\partial q}\bigg|_{m=m_0}=0$$

    $\Rightarrow$

    $$\frac{-8192(m+1)}{q^{m+2}} - \frac{64(m+1)\sqrt{2}}{q^{(m+3)/2}} + (m+1)q = 0$$

    此时，我们借助数值方法求出不同整数$m$下的最优$q$值以及对应的最小$H_1$，当：
    $$m = 7, q \approx 2.90$$

    时，$H_{\text{1}}$有最小值27.40。
\end{enumerate}

\textbf{2. 考虑更准确的critical path1}

在表\ref{tab:task3_p1_metrics}中我们认为反相器Xinv01的分支努力：

$$b = \frac{(16y+x_1)}{x_1}$$

但是事实上，当我们考虑从$A_0 \rightarrow word1$的关键路径时，$A_1$至$A_4$始终保持\textbf{低电平}，这也就意味着，所有连接到节点Xinv12但不在关键路径1上的15个NOR3门，其至少有一个输入端会处于高电平。这意味着无论A0电平如何切换，这些NOR3门的下拉网络必定导通，而上拉网络则保持关闭。因此，即使Xinv12的输出电平发生变化，与其输出端相连的所有NOR3门（路径上的那个除外）都将维持低电平输出。当Xinv12的输出电平切换时，这些NOR3门的输入门电容不会对延迟产生影响。换言之，在此条件下，我们可以认为Xinv12的分支努力等于1。

\section{Observations and conclusions}

对于本次实验任务的三个critical path的研究，我们能够得出的最重要的结论是：

\textbf{最小化crtical path延迟时，必须先经过手工模型的分析，得到一个粗略的最小延迟参数组合。然后在借助于仿真工具，在这个点附近进行扫描，可以快速收敛到仿真意义下的最优延迟。}

这里有两个重要的结论需要注意：
\begin{enumerate}
    \item 理论模型分析的重要性
    
    虽然我们能够借助仿真工具，让仿真工具在一系列参数下计算，最终返回给我们一个最优解。但是在没有至少一个粗略的参数范围的前提下，盲目的让仿真工具取遍历穷举所有解非常耗时，尤其是电路结果比较复杂的情况下。比如Task3中，一个5 to 32 decoder，\textbf{在通过理论分析确定大致范围的前提下}，依然有上千组点需要计算和仿真，这相当耗时。因此，通过理论分析，虽然往往不能直接给我们一个精确解，但是能够缩小我们扫描参数的范围，进而大幅缩短仿真工具求解的时间。

    \item 理论模型和实际的不一致性

    理论模型往往不能完全反映实际电路的行为，其给出的“最优解”在实际情况下往往也不是最优解，例如在Task1 to Task3中，所有逻辑努力分析法得出的最优解结果，都与仿真最优解有一定出入。因为我们在做理论分析时，对实际的电路元件进行了大幅简化，例如忽略部分小电容($C_{sb}, C_{db}$)，认为$\gamma = 1$等。一方面，这提示我们需要借助更加精确和繁琐的方法求解，这一点就是仿真工具所要帮助我们做的。另一方面，我们可以在可接受范围内不断精确我们的数学模型，从而提高其与实际电路行为的吻合度。
\end{enumerate}
