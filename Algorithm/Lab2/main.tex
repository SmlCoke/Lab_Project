\section{实验目的}

本实验旨在利用动态规划算法求解旅行商问题（Traveling Salesman Problem, TSP），并通过实现和优化多个版本的算法，深入理解动态规划的基本思想、状态转移方程的设计以及算法优化技巧。主要目标包括：

\begin{enumerate}
	\item 理解TSP问题的数学模型和动态规划求解方法
	\item 实现基于状态压缩的动态规划算法
	\item 对算法进行空间和时间上的优化
	\item 分析不同优化策略对算法性能的影响
	\item 统计动态规划过程中的子问题数量
	\item 与近似算法进行对比分析
\end{enumerate}

\section{算法原理}

\subsection{TSP问题描述}

旅行商问题（TSP）是组合优化领域的经典NP难问题。给定$n$个城市和每对城市之间的距离，要求找出一条访问每个城市恰好一次并返回起点的最短路径。形式化定义为：

给定完全加权图$G=(V,E)$，其中$V=\{0,1,\ldots,n-1\}$为城市集合，$d_{ij}$表示城市$i$到城市$j$的距离，目标是找到一个排列$\pi$，使得：

\begin{equation}
	\min \sum_{i=0}^{n-1} d_{\pi(i),\pi((i+1)\bmod n)}
\end{equation}

\subsection{动态规划解法}

\subsubsection{状态定义}

定义状态$dp[S][i]$表示从起点城市0出发，访问集合$S$中的所有城市，最后停留在城市$i$的最短路径长度。其中：
\begin{itemize}
	\item $S$是一个城市集合，用二进制掩码表示，第$k$位为1表示城市$k$在集合中
	\item $i \in S$，且$0 \in S$（起点必须在集合中）
	\item 最终答案为$\min_{i=1}^{n-1}\{dp[V][i] + d_{i,0}\}$，其中$V$表示所有城市的集合
\end{itemize}

\subsubsection{状态转移方程}

初始状态：$dp[\{0\}][0] = 0$

对于$|S| \geq 2$的状态转移：
\begin{equation}
	dp[S][i] = \min_{j \in S \setminus \{i\}} \{dp[S \setminus \{i\}][j] + d_{i,j}\}
\end{equation}

该状态转移方程的含义是：要计算到达城市$i$且访问过集合$S$中所有城市的最短路径，需要枚举上一个访问的城市$j$（$j \in S$且$j \neq i$），从已访问$S \setminus \{i\}$且停在$j$的状态转移过来。

\subsubsection{算法流程}

\begin{algorithm}[H]
	\caption{动态规划求解TSP}
	\begin{algorithmic}[1]
		\Require 邻接矩阵$adj[n][n]$，城市数量$n$
		\Ensure 最短路径长度和路径序列
		\State 初始化$dp[\{0\}][0] = 0$，其余为$\infty$
		\For{$k = 2$ to $n$} \Comment{按照集合大小递增}
		\For{所有大小为$k$且包含城市0的集合$S$}
		\For{$i \in S$且$i \neq 0$}
		\For{$j \in S \setminus \{i\}$}
		\State $dp[S][i] = \min(dp[S][i], dp[S \setminus \{i\}][j] + adj[i][j])$
		\EndFor
		\EndFor
		\EndFor
		\EndFor
		\State $result = \min_{i=1}^{n-1}\{dp[V][i] + adj[0][i]\}$
		\State \Return $result$和通过记录路径回溯得到的完整路径
	\end{algorithmic}
\end{algorithm}

\subsection{算法优化策略}

本实验实现了四个版本的动态规划算法，每个版本在前一版本基础上进行了优化：

\begin{enumerate}
	\item \textbf{solve\_TSP\_with\_dp}：基础版本，使用哈希表存储状态
	\item \textbf{solve\_TSP\_with\_dp\_fast}：使用二维数组替代哈希表，提高访问效率
	\item \textbf{solve\_TSP\_with\_dp\_fast\_v2}：利用起点固定为0的性质，将状态空间减半
	\item \textbf{solve\_TSP\_with\_dp\_fast\_v3}：使用滚动数组技术，进一步优化空间复杂度
\end{enumerate}

\section{结果分析}

\subsection{算法优化效果分析}

\begin{enumerate}
	\item \textbf{哈希表 vs 数组（v1 vs v2）}
	
	使用二维数组替代哈希表后，在att7上速度提升了3.67倍，在att20上提升了3.75倍。这是因为：
	\begin{itemize}
		\item 数组访问具有$O(1)$的常数时间复杂度，而哈希表需要计算哈希值并处理冲突
		\item 数组访问具有更好的缓存局部性
	\end{itemize}
	
	\item \textbf{状态空间压缩（v2 vs v3）}
	
	利用起点固定的特性将状态空间减半后，在att7上进一步提升了约18\%的性能（从0.0485ms降至0.0413ms）。在att20上也有约6.6\%的提升。空间复杂度从$O(2^n \cdot n)$降至$O(2^{n-1} \cdot n)$。
	
	\item \textbf{滚动数组优化（v3 vs v4）}
	
	v4版本使用滚动数组，理论上可以将空间复杂度降低到$O(C_n^k \cdot n)$，其中$k$是当前处理的集合大小。但实验结果显示：
	\begin{itemize}
		\item 在att7上，v4反而比v3慢（0.0772ms vs 0.0413ms）
		\item 在att20上，v4比v3慢得多（5402.87ms vs 1223.09ms）
	\end{itemize}
	
	这是因为v4需要频繁计算组合数索引，额外的计算开销超过了节省内存带来的收益。在内存充足的情况下，v3是最优选择。
\end{enumerate}

\section{结论}

通过本次实验，我们深入理解了动态规划算法在求解TSP问题中的应用，得出以下结论：

\begin{enumerate}
	\item \textbf{动态规划有效性}：基于状态压缩的动态规划算法能够在$O(n^2 \cdot 2^n)$时间内求解TSP问题的最优解，适用于$n \leq 20$的中小规模问题。
	
	\item \textbf{优化策略的重要性}：通过使用数组代替哈希表、压缩状态空间等优化手段，可以将算法性能提升3-4倍。但并非所有理论上的优化都能带来实际收益，需要权衡计算开销和内存访问效率。
	
	\item \textbf{子问题重复访问}：统计数据表明，动态规划过程中存在大量的子问题重复访问（平均9次/att20），验证了记忆化搜索的必要性。
	
	\item \textbf{精确算法的局限性}：尽管动态规划能够求得最优解，但其指数级的时间和空间复杂度限制了其在大规模问题上的应用。对于$n > 25$的问题，近似算法成为更实际的选择。
	
	\item \textbf{算法选择权衡}：在实际应用中，需要根据问题规模、解的质量要求和可用计算资源来选择合适的算法。对于要求最优解的中小规模问题，优化后的动态规划算法是最佳选择；对于大规模问题或对解的质量要求不高的场景，近似算法更为合适。
\end{enumerate}
