# 📘 **复数 n 次方根的统一表格**

| 知识点 | 结论 | 说明 |
| :--- | :--- | :--- |
| **1. 方程 $a^n = 1$**<br>（n 次单位根） | $\displaystyle a_k = e^{j\frac{2\pi k}{n}},\quad k=0,1,\ldots,n-1$ | 模长一定为 $1$；相位均匀分布，每间隔 $2\pi/n$ |
| **2. 方程 $a^n = b$**<br>（复数的 n 次方根） | $\displaystyle a_k = \|b\|^{1/n} e^{j\frac{\phi+2\pi k}{n}},\quad k=0,1,\ldots,n-1$ | $b = \|b\| e^{j\phi}$，每个根的模长为 $\|b\|^{1/n}$，相位等间隔分布。 |
| **3. 主根 × 单位根**<br>（统一公式） | $\displaystyle a_k = a_0 \cdot e^{j\frac{2\pi k}{n}}$ | 若 $a_0 = \|b\|^{1/n} e^{j\phi/n}$ 是方程 $a^n=b$ 的主根，则所有根是“主根 × 单位根”。n 次单位根为 $e^{j2\pi k/n}$。 |

---

# 🌟 一图流总结（记忆最方便）

* **求 $a^n = 1$**：只要“站在单位圆上的 $n$ 个等分点”。
* **求 $a^n = b$**：先找到一个主根 $\rightarrow$ 再让它在单位根作用下旋转。
* **所有复数 n 次方根 = 主根 × 单位根**（终极统一记忆公式）。
