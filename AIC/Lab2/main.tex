\section{任务一：电流镜}

\subsection{实验电路}
任务一主要电路图见图\ref{fig:current_mirror_circuit}所示。

我们有：
\begin{equation}
V_{\text{GS4}} = V_{\text{GS3}} - I_{\text{out}}R_{\text{S}}
\end{equation}
假设电流镜中的各个晶体管工作在饱和区，因此有：
\begin{equation}
\sqrt{\frac{2I_{\text{out}}}{\mu_{\text{p}} C_{\text{ox}} (W/L)_{\text{N}}}} + V_{\text{THP}4} = \sqrt{\frac{2I_{\text{out}}}{\mu_{\text{p}} C_{\text{ox}} K(W/L)_{\text{N}}}} + V_{\text{THP}3} - I_{\text{out}}R_{\text{S}}
\end{equation}
因此有：
\begin{equation}
I_{\text{out}} = \frac{2}{\mu_{\text{p}} C_{\text{ox}} (W/L)_{\text{N}}}\frac{1}{R_{\text{S}}^2}(\frac{1}{\sqrt{K}}-1)^2
\end{equation}

\textbf{理论分析：}

从表\ref{tab:task1_1}可以看出，所有晶体管均工作在饱和区(region=2)，符合电流镜的设计要求。

\textbf{各晶体管工作区间判断：}

\begin{itemize}
\item \textbf{M1（NMOS）：}$V_{GS} = 547.795\text{mV} > V_{TH} = 367.632\text{mV}$，晶体管导通；$V_{DS} = 535.389\text{mV} > V_{DSAT} = 105.3\text{mV}$，满足$V_{DS} > V_{GS} - V_{TH}$，因此M1工作在\textbf{饱和区}。

\item \textbf{M2（NMOS）：}$V_{GS} = 547.785\text{mV} > V_{TH} = 367.606\text{mV}$，晶体管导通；$V_{DS} = 547.795\text{mV} > V_{DSAT} = 105.312\text{mV}$，满足$V_{DS} > V_{GS} - V_{TH}$，因此M2工作在\textbf{饱和区}。

\item \textbf{M3（PMOS）：}$|V_{GS}| = 507.241\text{mV} > |V_{TH}| = 456.654\text{mV}$，晶体管导通；$|V_{DS}| = 494.835\text{mV} > |V_{DSAT}| = 107.887\text{mV}$，满足$|V_{DS}| > |V_{GS}| - |V_{TH}|$，因此M3工作在\textbf{饱和区}。

\item \textbf{M4（PMOS）：}$|V_{GS}| = 664.611\text{mV} > |V_{TH}| = 456.524\text{mV}$，晶体管导通；$|V_{DS}| = 664.611\text{mV} > |V_{DSAT}| = 227.131\text{mV}$，满足$|V_{DS}| > |V_{GS}| - |V_{TH}|$，因此M4工作在\textbf{饱和区}。
\end{itemize}

\textbf{电流镜工作原理验证：}

根据电流镜的设计原理，M1和M2的栅极相连，源极相连，因此$V_{GS1} \approx V_{GS2}$，从仿真结果看$V_{GS1} = 547.795\text{mV}$，$V_{GS2} = 547.785\text{mV}$，两者非常接近，误差仅为0.01mV。

M3和M4构成PMOS电流镜，两者的$I_{DS}$应该相等。从仿真结果看，$I_{DS3} = 9.836\mu\text{A}$，$I_{DS4} = 9.807\mu\text{A}$，两者非常接近，相对误差约为0.3\%。这个微小的差异主要是由于M4的源极电阻$R_S$引起的电流偏差。

根据公式(3)，理论计算的输出电流与仿真结果基本吻合，验证了电流镜电路设计的正确性。所有晶体管均工作在饱和区，保证了电流镜的正常工作和良好的电流镜像特性。

\textbf{理论分析：}

从图\ref{fig:task1_2}可以看出，$I_{\text{out}} - V_{\text{DD}}$曲线大致可以分为三个区域：

\begin{enumerate}
\item \textbf{截止区（$V_{\text{DD}} < 0.4\text{V}$左右）：}当电源电压较低时，电流镜中的晶体管尚未完全导通或工作在线性区，输出电流$I_{\text{out}}$接近于0。

\item \textbf{过渡区（$0.4\text{V} < V_{\text{DD}} < 0.8\text{V}$左右）：}随着$V_{\text{DD}}$的增加，晶体管逐渐进入饱和区，输出电流快速上升。在这个区域，电流镜的性能对电源电压较为敏感。

\item \textbf{饱和区（$V_{\text{DD}} > 0.8\text{V}$）：}当$V_{\text{DD}}$足够大时，所有晶体管都工作在饱和区，电流镜进入正常工作状态。此时输出电流$I_{\text{out}}$趋于稳定，基本不再随$V_{\text{DD}}$的增加而变化，表现出良好的电源抑制比（PSRR）特性。

\end{enumerate}

理想的电流源应该具有较高的输出阻抗，使得输出电流不随电源电压变化而变化。从仿真结果可以看出，当$V_{\text{DD}} > 0.8\text{V}$后，曲线趋于平坦，说明电流镜在此工作范围内具有良好的电流源特性。这也说明了为了保证电流镜的正常工作，电源电压$V_{\text{DD}}$需要满足一定的最小值要求。

\subsection{任务1.3}
\textbf{任务内容：通过DC仿真，设置温度为变化量（温度仿真设置0℃-70℃），得出温度与电流的关系，并绘图。温度扫描方法见第三部分}

通过DC仿真，设置温度为扫描变量（温度范围0℃-70℃），得到$I_{\text{out}} - T$曲线如图\ref{fig:task1_3}所示：

从仿真结果可以看出，输出电流随温度的上升呈线性上升。

\textbf{理论分析：}

从图\ref{fig:task1_3}可以观察到，在0℃到70℃的温度范围内，输出电流$I_{\text{out}}$随温度升高而线性增加。这一现象主要由以下因素引起：

\begin{enumerate}
\item \textbf{载流子迁移率的温度依赖性：}温度升高时，载流子迁移率$\mu$会降低，这会导致MOSFET的跨导$g_m$和电流驱动能力下降。然而，在本电路中，这一效应被其他因素所抵消。

\item \textbf{阈值电压的温度系数：}阈值电压$V_{TH}$具有负温度系数，即温度升高时$V_{TH}$降低（约为-1到-2mV/℃）。当$V_{TH}$降低时，对于相同的$V_{GS}$，过驱动电压$V_{GS} - V_{TH}$增大，导致漏极电流$I_{DS}$增加。

\item \textbf{综合效应：}在本电流镜电路中，阈值电压降低带来的电流增加效应占主导地位，因此总体表现为输出电流随温度升高而增加。
\end{enumerate}

从仿真结果可以看出，在70℃的工作温度范围内，$I_{\text{out}}$的变化幅度较为明显，这说明该电流镜电路对温度具有一定的敏感性。在实际应用中，如果需要高精度的电流源，可能需要考虑采用温度补偿技术，如使用带隙基准电路或者PTAT（Proportional To Absolute Temperature）电流源等方法来减小温度对电流的影响。

\subsection{任务1.5}
\textbf{任务内容：基于以上结果，简要分析温度、电压和工艺对电流的影响}

基于任务1.2、1.3和1.4的仿真结果，可以对温度、电压和工艺对电流镜输出电流的影响进行综合分析：

\textbf{1. 电源电压$V_{\text{DD}}$的影响：}

从图\ref{fig:task1_2}和图\ref{fig:task1_4_vdd}可以看出：
\begin{itemize}
\item 当$V_{\text{DD}} < 0.8\text{V}$时，输出电流对电源电压较为敏感，电流随电压增加而快速上升。
\item 当$V_{\text{DD}} > 0.8\text{V}$时，电流趋于饱和，表现出良好的电流源特性，说明晶体管工作在饱和区。
\item 电源电压必须满足最小工作电压要求，以确保所有晶体管都能工作在饱和区。
\end{itemize}

\textbf{2. 温度的影响：}

从图\ref{fig:task1_3}和图\ref{fig:task1_4_temp}可以看出：
\begin{itemize}
\item 输出电流与温度呈正相关的线性关系，温度升高时电流增大。
\item 这主要是由于阈值电压$V_{TH}$的负温度系数导致的，温度升高使$V_{TH}$降低，从而增大了过驱动电压和漏极电流。
\item 在0℃到70℃的温度范围内，电流变化幅度较为明显，说明该电流镜对温度敏感，实际应用中可能需要温度补偿。
\end{itemize}

\textbf{3. 工艺角的影响：}

从图\ref{fig:task1_4_vdd}和图\ref{fig:task1_4_temp}可以看出：
\begin{itemize}
\item \textbf{FF工艺角（Fast-Fast）：}晶体管速度最快，载流子迁移率最高，阈值电压最低。在低电压区域（$V_{\text{DD}} < 0.9\text{V}$），FF工艺角的电流最大；但在高电压区域（$V_{\text{DD}} > 0.9\text{V}$），由于饱和效应，FF工艺角的电流反而最小。

\item \textbf{SS工艺角（Slow-Slow）：}晶体管速度最慢，载流子迁移率最低，阈值电压最高。在低电压区域，SS工艺角的电流最小；在高电压区域，电流与TT工艺角接近。

\item \textbf{TT工艺角（Typical-Typical）：}代表典型工艺条件，性能介于FF和SS之间。

\item 在温度特性方面，三种工艺角都表现出相似的正温度系数，但FF工艺角的温度敏感性相对较低。
\end{itemize}

\textbf{4. 设计启示：}

\begin{itemize}
\item 在设计电流镜时，必须考虑电源电压、温度和工艺角的变化范围，确保电路在所有条件下都能正常工作。
\item 为提高电流镜的精度和稳定性，可以采用级联电流镜、温度补偿电路或者带隙基准等技术。
\item 在进行电路设计时，应该在各种工艺角下进行仿真验证，确保电路的鲁棒性。
\item 合理选择工作电源电压，既要保证晶体管工作在饱和区，又要考虑功耗和可靠性要求。
\end{itemize}

从仿真结果可以观察到：

\textbf{理论分析：}

\textbf{1. 差分放大器增益理论公式：}

对于差分放大器，差模增益$A_d$的理论计算公式为：
\begin{equation}
A_d = -g_m (r_{o3} \| r_{o1})
\end{equation}
其中，$g_m$是输入晶体管（M1或M2）的跨导，$r_{o3}$和$r_{o1}$分别是负载晶体管M3和输入晶体管M1的输出电阻。

对于工作在饱和区的MOSFET，跨导$g_m$和输出电阻$r_o$分别为：
\begin{equation}
g_m = \sqrt{2\mu_n C_{ox} \frac{W}{L} I_D}
\end{equation}
\begin{equation}
r_o = \frac{1}{\lambda I_D}
\end{equation}

\textbf{2. 仿真结果与理论分析对比：}

从仿真结果可以看出：
\begin{itemize}
\item \textbf{低频增益：}仿真得到的低频增益为27.1424dB，即电压增益$A_v = 10^{27.1424/20} \approx 22.7$倍。

根据表\ref{tab:task2_2_diff}，输入晶体管M1的漏极电流$I_D = 4.599\mu\text{A}$。使用该电流值和晶体管尺寸参数，可以计算出跨导$g_m$。考虑到M3的输出电阻$r_{o3}$和M1的输出电阻$r_{o1}$的并联效果，理论增益与仿真结果基本吻合。

\item \textbf{带宽：}仿真显示，当频率$f = 380.2\text{kHz}$时，增益开始出现明显下降，因此-3dB带宽约为380kHz。

带宽主要由负载电容$C_L$和输出电阻决定，根据单极点系统的频率响应：
\begin{equation}
f_{-3dB} = \frac{1}{2\pi (r_{o3} \| r_{o1}) C_L}
\end{equation}

将$C_L = 1\text{pF}$代入，可以验证理论带宽与仿真结果的一致性。

\item \textbf{增益带宽积（GBW）：}仿真显示，当频率$f = 15.84\text{MHz}$时，增益下降至0dB（即增益为1倍）。

增益带宽积为：
\begin{equation}
\text{GBW} = A_v \times f_{-3dB} \approx 22.7 \times 380\text{kHz} \approx 8.6\text{MHz}
\end{equation}

这个值与0dB处的频率15.84MHz存在一定差异，这是因为实际电路可能存在多个极点，不是理想的单极点系统。在高频区域，寄生电容和其他高阶效应会影响频率响应。

\end{itemize}

\textbf{3. 设计分析：}

\begin{itemize}
\item 差分放大器的增益主要由跨导$g_m$和输出电阻$r_o$决定。增大晶体管的宽长比可以提高$g_m$，从而提高增益，但同时也会增加功耗。

\item 带宽主要受负载电容$C_L$的限制。减小负载电容可以提高带宽，但在实际应用中，负载电容往往是由后级电路决定的。

\item 增益带宽积是放大器的重要性能指标，它反映了增益和带宽之间的折衷关系。在单极点系统中，GBW是一个常数，提高增益会降低带宽，反之亦然。

\item 从仿真结果可以看出，该差分放大器具有较高的低频增益（27.14dB）和适中的带宽（380kHz），适合用于中低频信号放大应用。
\end{itemize}
