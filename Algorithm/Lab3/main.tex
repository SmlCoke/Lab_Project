\section{实验步骤}

\subsection{模拟退火算法原理}

模拟退火算法是一种启发式全局优化方法，其灵感来源于固体退火过程。算法通过引入随机性来避免陷入局部最优解，其核心思想如下：

\begin{enumerate}
	\item \textbf{初始化}：设定初始温度$T_0$、终止温度$T_t$、降温因子$\alpha$
	\item \textbf{扰动生成}：在当前解的邻域内随机产生一个新解
	\item \textbf{接受准则}：根据Metropolis准则决定是否接受新解
	\item \textbf{降温}：按照降温策略更新温度
	\item \textbf{终止}：当温度降至终止温度时，算法结束
\end{enumerate}

Metropolis接受准则是模拟退火的核心，其数学表达式为：
\[
P(\text{接受新解}) = 
\begin{cases}
1 & \text{if } \Delta E > 0 \text{ （新解更优）} \\
e^{\Delta E / T} & \text{if } \Delta E \leq 0 \text{ （新解较差）}
\end{cases}
\]
其中$\Delta E = E_{\text{new}} - E_{\text{old}}$是新旧解的能量差（本实验中为得分差，得分越高越好，因此当$\Delta E > 0$时直接接受，当$\Delta E < 0$时，根据当前温度情况概率接受），$T$为当前温度。

\subsection{模拟退火算法伪代码}

\begin{algorithm}[H]
	\caption{模拟退火算法 Simulated Annealing}
	\begin{algorithmic}[1]
		\Require 初始解$S_0$，初始温度$T_0$，终止温度$T_t$，降温因子$\alpha$，每温度迭代次数$times$
		\Ensure 优化后的解$S_{best}$
		\State $S_{\text{cur}} \gets S_0$, $T \gets T_0$
		\While{$T > T_t$}
			\For{$i = 1$ to times}
				\State $S_{\text{new}} \gets$ 在$S_{\text{cur}}$邻域内随机生成新解
				\If{$S_{\text{new}}$合法}
					\State $\Delta E \gets \text{Score}(S_{\text{new}}) - \text{Score}(S_{\text{cur}})$
					\If{$\Delta E > 0$ \textbf{or} $\text{random}(0,1) < e^{\Delta E/T}$}
						\State $S_{\text{cur}} \gets S_{\text{new}}$ \Comment{接受新解}
					\EndIf
				\EndIf
			\EndFor
			\State $T \gets \alpha T$ \Comment{降温}
		\EndWhile
		\State \Return $S_{cur}$
	\end{algorithmic}
\end{algorithm}

\subsubsection{TODO 1: 随机选择位置并调用is\_legal}

从占用位置列表\texttt{occupy}和空位置列表\texttt{empty}中各随机选择一个位置，调用\texttt{is\_legal}函数判断将MOS管从占用位置（即occupy[i]）移动到空位置（即empty[j]）是否合法。is\_legal()函数内部会自动尝试各种翻转组合来找到合法布局。
\begin{lstlisting}
// 创建随机分布
std::uniform_int_distribution<int> dist_occ(0, 
    static_cast<int>(occupy.size()) - 1);
std::uniform_int_distribution<int> dist_emp(0, 
    static_cast<int>(empty.size()) - 1);
int i = dist_occ(rng);  // 随机选择占用位置索引
int j = dist_emp(rng);  // 随机选择空位置索引

bool legal;
vector<Mos> pary, nary;
vector<optional<Mos>> pplace, nplace;

if (tp) {  // PMOS行
    std::tie(legal, pary, nary, pplace, nplace) = 
        is_legal(cur_pmos, cur_nmos, cur_pp, cur_np, 
                 occupy[i], empty[j]);
	// 对于 PMOS 行，传入顺序是 (pmos, nmos, pp, np, occupy[i], empty[j])
} else {   // NMOS行，需要交换参数顺序
    std::tie(legal, nary, pary, nplace, pplace) = 
        is_legal(cur_nmos, cur_pmos, cur_np, cur_pp, 
                 occupy[i], empty[j]);
	// 对于 NMOS 行，传入顺序是 (nmos, pmos, np, pp, occupy[i], empty[j])
}
\end{lstlisting}

\subsubsection{TODO 3: Metropolis接受准则}

实现Metropolis接受准则，决定是否接受候选解。这里dist01(rng)用于随机生成一个0到1之间的浮点数，用作概率与当前温度下的阈值概率比较。

\begin{lstlisting}
double delta = s1 - s0;  // 得分差，正值表示新解更好
bool accept = false;

if (delta > 0) {
    // 新解更好，直接接受
    accept = true;
} else {
    // 新解更差，以概率e^(delta/t)接受
    double threshold = std::exp(delta / t);
    if (dist01(rng) < threshold) {
        accept = true;
    }
}
\end{lstlisting}

\subsubsection{TODO 4: 接受后更新当前解}

当新解被接受时，更新当前解并在行末尾追加空位。

\begin{lstlisting}
if (accept) {
    cur_pmos = new_pary;
    cur_nmos = new_nary;
    cur_pp = new_pp2;
    cur_np = new_np2;
    
    // 追加空位，为后续扰动预留空间
    cur_pp.push_back(std::nullopt);
    cur_pp.push_back(std::nullopt);
    cur_np.push_back(std::nullopt);
    cur_np.push_back(std::nullopt);
    
    // 行切换逻辑
    if (tp) {
        if (!cur_nmos.empty()) tp = !tp;
    } else {
        if (!cur_pmos.empty()) tp = !tp;
    }
}
\end{lstlisting}

\subsection{批量实验运行脚本}

为了方便批量运行不同参数组合的实验，编写了\texttt{run\_flow.py}脚本。该脚本能够自动完成模拟退火算法运行、评分计算、迭代曲线绘制的全流程，支持遍历多组参数组合进行对比实验。

\begin{lstlisting}[language=Python]
import subprocess
import os

if __name__ == "__main__":
    T0 = [10000, 20000]       # 起始温度系数
    TT = [1]                   # 终止温度系数
    de = [5, 7, 88]            # 降温因子(0.5, 0.7, 0.88)
    times = [1000, 2000]       # 每温度迭代次数系数

    for t0 in T0:
        for t in TT:
            for d in de:
                for time in times:
                    # 构造目录名
                    dir_name = f'{t0}_{t}_{d}_{time}'
                    # 'greedy_results'可改为'results'用于SA实验
                    result_dir = os.path.join('greedy_results', dir_name)
                    
                    # 如果目录不存在则创建
                    if not os.path.exists(result_dir):
                        os.makedirs(result_dir)
                    
                    print(f"Running flow for: {dir_name}")

                    # 1. 运行 eda.py
                    process_log_path = os.path.join(result_dir, 'process.txt')
                    data_csv_path = os.path.join(result_dir, 'data.csv')
                    
                    with open(process_log_path, 'w', encoding='utf-8') as f_log:
                        subprocess.run(['python', 
                                        'eda.py', 
                                        'cells.spi',
                                        'AN2D2',
                                        data_csv_path,
                                        str(t0),
                                        f'0.{d}',  # d=5->0.5, d=7->0.7, d=88->0.88
                                        str(time)],
                                        stdout=f_log)
                    
                    # 2. 运行 evaluator.py
                    score_log_path = os.path.join(result_dir, 'score.txt')
                    with open(score_log_path, 'w', encoding='utf-8') as f_score:
                        subprocess.run(['python', 
                                        'evaluator.py', 
                                        'AN2D2.json',
                                        'AN2D2',
                                        'cells.spi'],
                                        stdout=f_score)
                    
                    # 3. 运行 plot_iter.py
                    subprocess.run(['python', 
                                    'plot_iter.py', 
                                    data_csv_path,
                                    'log'])
\end{lstlisting}

该脚本的主要功能如下：
\begin{enumerate}
	\item \textbf{参数遍历}：通过嵌套循环遍历所有参数组合（起始温度$T_0$、降温因子$\alpha$、每温度迭代次数$times$）
	\item \textbf{目录管理}：自动创建以参数命名的结果目录，便于管理不同实验的输出
	\item \textbf{全流程自动化}：依次执行模拟退火算法（eda.py）、评分计算（evaluator.py）、曲线绘制（plot\_iter.py）
	\item \textbf{日志记录}：将运行日志和评分结果保存到文件，便于后续分析
\end{enumerate}

使用该脚本进行贪心算法与模拟退火算法的对比实验时，只需修改\texttt{result\_dir}变量（如改为\texttt{greedy\_results}或\texttt{results}），并在重新编译前修改\texttt{sa\_core.cpp}中的接受准则即可切换算法模式。

\begin{enumerate}
	\item 起始温度$T_0$： $x \times \text{mos\_num}$，其中mos\_num为当前单元的MOS管数量
	\item 终止温度$T_t$：$0.y$，在本次实验中固定为0.1
	\item 降温因子$\alpha$：$0.z$，如88表示0.88
	\item 每温度迭代次数$times$：$w \times \text{mos\_num}$
\end{enumerate}

\section{分析与讨论}

\subsection{参数影响分析}

\subsubsection{降温因子$\alpha$的影响}

\begin{itemize}
	\item \textbf{较大的$\alpha$（如0.88）}：降温较慢，算法有更多时间在每个温度水平进行探索，有利于找到更优解，但运行时间较长。
	\item \textbf{较小的$\alpha$（如0.70）}：降温较快，算法更快收敛，但可能过早陷入局部最优。
\end{itemize}

\subsubsection{每温度迭代次数$times$的影响}

\begin{itemize}
	\item \textbf{较大的$times$}：每个温度下进行更多扰动尝试，增加找到更优解的概率，但增加计算时间。
	\item \textbf{较小的$times$}：减少计算时间，但可能导致搜索不充分。
\end{itemize}

\subsubsection{起始温度$T_0$的影响}

\begin{itemize}
	\item \textbf{较高的$T_0$}：初期接受差解的概率高，有利于跳出局部最优，探索范围更广。
	\item \textbf{较低的$T_0$}：初期即表现出较强的贪心性质，可能错过全局最优。
\end{itemize}

\subsection{SA与贪心算法的效果差异}

贪心算法是模拟退火算法的简化版本，其核心区别在于Metropolis准则：贪心算法只接受使目标函数改进的解（即$\Delta E > 0$时才接受），而模拟退火算法即使在$\Delta E < 0$时也有一定概率接受较差解。

\subsubsection{贪心算法的实现方式}

在代码实现上，只需修改\texttt{sa\_core.cpp}中的Metropolis接受准则部分，将概率接受改为只接受改进解：
\begin{lstlisting}
// 贪心算法：只接受改进解
if (delta > 0) {
    accept = true;  // 新解更好，接受
} else {
    accept = false; // 新解更差，拒绝
}
\end{lstlisting}

\subsubsection{结果分析}

从实验数据可以得出以下结论：

\begin{enumerate}
	\item \textbf{SA算法整体优于贪心算法}：在所有12组对比实验中，模拟退火算法的得分均高于贪心算法，得分差值范围为0.84\textasciitilde8.05分。
	
	\item \textbf{SA最优得分（96.69分）显著高于贪心最优得分（94.06分）}：模拟退火算法能够找到更优的全局解，而贪心算法容易陷入局部最优。
	
	\item \textbf{贪心算法结果波动较大}：贪心算法的得分范围为88.64\textasciitilde94.06分，标准差较大；而模拟退火算法的得分集中在较高水平。
	
	\item \textbf{SA的概率接受机制是关键}：模拟退火算法通过在高温阶段以一定概率接受较差解，能够跳出局部最优，探索更广阔的解空间，最终收敛到更优的解。
\end{enumerate}

\subsection{实验总结与收获}

\begin{enumerate}
	\item \textbf{理解了模拟退火算法的核心思想}：通过引入随机性（Metropolis准则）来避免陷入局部最优，在高温时广泛探索，低温时精细收敛。
	
	\item \textbf{掌握了模拟退火的完整流程}：邻域产生$\rightarrow$合法性检查$\rightarrow$目标函数评分$\rightarrow$接受准则$\rightarrow$降温策略。
	
	\item \textbf{理解了参数调节的重要性}：不同的参数组合会显著影响算法的收敛速度和最终解的质量，需要根据具体问题进行调优。
	
	\item \textbf{实践了C++与Python的混合编程}：通过pybind11将计算密集型的C++代码封装为Python模块，兼顾了性能和易用性。
\end{enumerate}
